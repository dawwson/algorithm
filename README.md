# 알고리즘 문제 풀이

- 학습 플랫폼
  - [프로그래머스](https://programmers.co.kr/)
  - [리트코드](https://leetcode.com/)
  - [백준](https://www.acmicpc.net/)

- 학습 루틴
  1. 학습 플랫폼에서 문제를 1개 선정하여 30분 동안 푼다.

  2. 문제 당 30분 내에 풀지 못할 경우, AI를 통해 문제에 대한 힌트를 얻어서 다시 풀어본다.

  3. [템플릿](https://github.com/dawwson/algorithm/blob/main/template.md)에 맞춰 내용을 정리한다.

     ````
     ./programmers/level2/새 문제.md를 만들고 아래 Java 풀이를 기준으로 문서화해줘.
      문제 링크는 ...이고 코드는 다음과 같아.

      ```java
      // 코드
     ````

- 사용 언어
  - 1순위: `Java`
    - 주력 언어에 좀 더 집중하기 위함.

  - 2순위: `JavaScript` / `TypeScript`
