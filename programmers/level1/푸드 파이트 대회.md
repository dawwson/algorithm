### Intuition

---

- 두 선수에게 같은 종류와 수량의 음식을 같은 순서로 배치해야 하므로 전체 배열은 물 `0`을 중심으로 좌우가 대칭이어야 한다.
- 종류 `i`의 음식이 `food[i]`개 있다면 두 선수에게 동일하게 배분할 수 있는 수량은 한 명당 `food[i] / 2`개이다.
- 홀수 개의 음식에서 남는 한 개는 두 선수에게 공평하게 나눌 수 없으므로 사용하지 않는다.
- 한쪽 선수의 음식 배치를 번호가 작은 음식부터 만들고, 이를 뒤집어 반대쪽 배치로 사용하면 대칭 구조를 만들 수 있다.
- 반복적인 문자열 추가 비용을 줄이기 위해 한쪽 배치를 `StringBuilder`에 저장한다.

<br>

### Approach

---

- 한쪽 선수의 음식 순서를 만들 `StringBuilder sb`를 생성한다.
- `food[0]`은 가운데에 놓을 물이므로 음식 종류 `1`부터 마지막 종류까지 순회한다.
- 각 음식 종류 `i`에 대해 `food[i] / 2`를 계산하여 한 선수가 먹을 수량 `count`를 구한다.
- 음식 번호 `i`를 문자열로 변환하고 `repeat(count)`로 반복하여 `sb`에 추가한다.
- 반복이 끝난 뒤 반환 표현식은 다음 순서로 결과를 만든다.
  - `sb.toString()`으로 원래 순서의 왼쪽 음식 배치를 만든다.
  - 가운데에 물을 나타내는 `"0"`을 추가한다.
  - `sb.reverse()`로 기존 `StringBuilder`를 뒤집고 문자열로 변환하여 오른쪽 음식 배치를 추가한다.
- 완성된 대칭 문자열을 반환한다.

<br>

### Complexity

---

- Time complexity: `O(f + L)`
  - `f`는 `food`의 길이이고, `L`은 최종 결과 문자열의 길이이다.
  - 모든 음식 종류를 한 번 순회하는 데 `O(f)`가 필요하다.
  - 음식 번호 반복과 추가, `StringBuilder` 뒤집기, 최종 문자열 생성은 생성되는 전체 문자 수에 비례하므로 `O(L)`이다.

- Space complexity: `O(L)`
  - 한쪽 음식 배치를 저장하는 `StringBuilder`와 최종 결과 문자열이 결과 길이에 비례하는 공간을 사용한다.

<br>

### Code (Java)

---

```java
class Solution {
    public String solution(int[] food) {
        
        StringBuilder sb = new StringBuilder();
        
        for (int i = 1; i < food.length; i++) {
            int count = food[i] / 2;
            
            sb.append(Integer.toString(i).repeat(count));
        }
        
        return sb.toString() + "0" + sb.reverse().toString();
    }
}
```
