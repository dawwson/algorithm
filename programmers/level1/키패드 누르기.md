### Intuition

---

- `1`, `4`, `7`은 항상 왼손으로 누르고 `3`, `6`, `9`는 항상 오른손으로 누른다.
- 가운데 열의 `2`, `5`, `8`, `0`은 현재 두 손의 위치에서 목표 키까지 이동하는 거리를 비교해야 한다.
- 키패드에서는 상하좌우로만 이동하므로 필요한 거리는 두 키 사이의 행 차이와 열 차이를 더한 값이다.
- Java 구현은 이 거리를 매번 계산하지 않고, 가운데 키마다 다른 키까지의 거리를 문자열에 미리 저장해 인덱스로 조회한다.
- 두 손의 거리가 같을 때만 `hand`에 지정된 주 사용 손을 선택한다.

<br>

### Approach

---

- 결과를 효율적으로 이어 붙이기 위해 `StringBuilder`를 생성한다.
- 왼쪽, 가운데, 오른쪽 열의 숫자를 각각 `left`, `middle`, `right` 문자열로 구분한다.
- 왼손의 초기 위치를 `*`, 오른손의 초기 위치를 `#`으로 설정한다.
- 가운데 키 `2`, `5`, `8`, `0`에서 다른 키까지의 거리를 `distanceFrom2`, `distanceFrom5`, `distanceFrom8`, `distanceFrom0`에 저장한다.
  - 문자열의 `0`부터 `9`까지 인덱스는 해당 숫자 키를 나타낸다.
  - `*`와 `#`은 어느 가운데 키에서도 거리가 같으므로 둘 다 인덱스 `10`을 사용한다.
- `numbers`를 순회하며 각 숫자를 문자열 `n`으로 변환한다.
  - 왼쪽 열의 숫자이면 `L`을 추가하고 왼손 위치를 갱신한다.
  - 오른쪽 열의 숫자이면 `R`을 추가하고 오른손 위치를 갱신한다.
  - 가운데 열의 숫자이면 현재 두 손의 위치를 거리 문자열에서 사용할 인덱스로 변환한다.
  - 목표 숫자에 대응하는 거리 문자열의 문자를 읽고 `'0'`을 빼 정수 거리로 변환한다.
  - 거리가 더 짧은 손을 선택하며, 거리가 같으면 `hand`에 지정된 손을 선택한다.
  - 선택한 손에 해당하는 문자를 결과에 추가하고 그 손의 현재 위치를 갱신한다.
- 모든 숫자를 처리한 뒤 `StringBuilder`를 문자열로 변환해 반환한다.

<br>

### Complexity

---

- Time complexity: `O(n)`
  - `n`은 `numbers`의 길이이다.
  - 모든 숫자를 한 번씩 처리하며, 열 확인과 미리 저장된 거리 조회는 고정 길이 문자열을 대상으로 하므로 각각 `O(1)`이다.
  - `StringBuilder`의 문자 추가는 분할 상환 `O(1)`이다.

- Space complexity: `O(n)`
  - 반환할 `n`개의 `L` 또는 `R` 문자를 `StringBuilder`에 저장한다.
  - 키 분류와 거리 정보 문자열은 입력 크기와 무관한 고정 크기이므로 `O(1)`이다.

### Code (Java)

---

```java
class Solution {
    public String solution(int[] numbers, String hand) {

        StringBuilder answer = new StringBuilder();

        String left = "147";
        String middle = "2580";
        String right = "369";

        String currentLeft = "*";
        String currentRight = "#";

        // 중간 버튼에서 다른 버튼까지의 거리 (0123456789*)
        String distanceFrom2 = "31012123234";
        String distanceFrom5 = "22121012123";
        String distanceFrom8 = "13232121012";
        String distanceFrom0 = "04343232121";

        for (int number : numbers) {
            String n = String.valueOf(number);

            if (left.contains(n)) {
                answer.append("L");
                currentLeft = n;
                continue;
            }

            if (right.contains(n)) {
                answer.append("R");
                currentRight = n;
                continue;
            }

            if (middle.contains(n)) {
                int leftIndex = "*#".contains(currentLeft) ? 10 : Integer.parseInt(currentLeft);
                int rightIndex = "*#".contains(currentRight) ? 10 : Integer.parseInt(currentRight);

                int leftDistance = 0;
                int rightDistance = 0;

                if (n.equals("2")) {
                    leftDistance = distanceFrom2.charAt(leftIndex) - '0';
                    rightDistance = distanceFrom2.charAt(rightIndex) - '0';
                }
                if (n.equals("5")) {
                    leftDistance = distanceFrom5.charAt(leftIndex) - '0';
                    rightDistance = distanceFrom5.charAt(rightIndex) - '0';
                }
                if (n.equals("8")) {
                    leftDistance = distanceFrom8.charAt(leftIndex) - '0';
                    rightDistance = distanceFrom8.charAt(rightIndex) - '0';
                }
                if (n.equals("0")) {
                    leftDistance = distanceFrom0.charAt(leftIndex) - '0';
                    rightDistance = distanceFrom0.charAt(rightIndex) - '0';
                }

                if (leftDistance == rightDistance) {
                    if (hand.equals("left")) {
                        answer.append("L");
                        currentLeft = n;
                    } else {
                        answer.append("R");
                        currentRight = n;
                    }
                } else if (leftDistance < rightDistance) {
                    answer.append("L");
                    currentLeft = n;
                } else {
                    answer.append("R");
                    currentRight = n;
                }
                continue;
            }
        }
        return answer.toString();
    }
}
```

### Code (Python)

---

```python
def solution(numbers, hand):
    answer = ''

    # 왼쪽/중간/오른쪽 키패드
    lefts = [1, 4, 7]
    middles = [2, 5, 8, 0]
    rights = [3, 6, 9]
    # 현재 왼손/오른손 위치
    current_left = '*'
    current_right = '#'

    # 중간 키패드로부터 다른 키패드까지의 이동 거리
    distance = {
        2: {1: 1, 2: 0, 3: 1, 4: 2, 5: 1, 6: 2, 7: 3, 8: 2, 9: 3, '*': 4, 0: 3, '#': 4},
        5: {1: 2, 2: 1, 3: 2, 4: 1, 5: 0, 6: 1, 7: 2, 8: 1, 9: 2, '*': 3, 0: 2, '#': 3},
        8: {1: 3, 2: 2, 3: 3, 4: 2, 5: 1, 6: 2, 7: 1, 8: 0, 9: 1, '*': 2, 0: 1, '#': 2},
        0: {1: 4, 2: 3, 3: 4, 4: 3, 5: 2, 6: 3, 7: 2, 8: 1, 9: 2, '*': 1, 0: 0, '#': 1}
    }

    for number in numbers:
        # 왼쪽 키패드인 경우
        if number in lefts:
            answer += 'L'
            current_left = number
        # 오른쪽 키패드인 경우
        if number in rights:
            answer += 'R'
            current_right = number
        # 중간 키패드인 경우
        if number in middles:
            # 키패드에서 현재 왼손/오른손까지의 이동 거리
            left_distance = distance[number][current_left]
            right_distance = distance[number][current_right]

            if left_distance < right_distance:
                answer += 'L'
                current_left = number
            if left_distance > right_distance:
                answer += 'R'
                current_right = number
            if left_distance == right_distance:
                # 왼손잡이인 경우
                if hand == 'left':
                    answer += 'L'
                    current_left = number
                # 오른손잡이인 경우
                if hand == 'right':
                    answer += 'R'
                    current_right = number
    return answer
```

- 왼쪽, 가운데, 오른쪽 열을 리스트로 구분하고 현재 두 손의 위치를 갱신하며 숫자를 순서대로 처리한다.
- 가운데 키와 각 손 사이의 거리는 미리 만든 중첩 딕셔너리에서 조회하고, 거리가 같으면 주 사용 손을 선택한다.
- 입력 숫자의 개수를 `n`이라 할 때 반복적인 문자열 연결을 기준으로 최악의 시간 복잡도는 `O(n²)`, 결과 문자열과 고정 크기 거리표를 포함한 보조 공간 복잡도는 `O(n)`이다.
