### Intuition

---

- 두 수의 공약수를 하나씩 검사하는 대신 유클리드 호제법을 사용하면 나머지 연산을 반복하여 최대공약수를 빠르게 구할 수 있다.
- 유클리드 호제법은 `a`와 `b`의 최대공약수가 `b`와 `a % b`의 최대공약수와 같다는 성질을 이용한다.
- 나머지가 `0`이 되면 마지막으로 나눈 수가 최대공약수이다.
- 두 양의 정수의 곱은 최대공약수와 최소공배수의 곱과 같으므로, 최대공약수를 구한 뒤 `n * m / gcd`로 최소공배수를 계산할 수 있다.

<br>

### Approach

---

- `getGcd(n, m)`을 호출해 두 수의 최대공약수를 구한다.
- `getGcd(a, b)`는 다음과 같이 재귀적으로 동작한다.
  - `b`가 `0`이면 나머지 연산이 끝난 것이므로 `a`를 반환한다.
  - 그렇지 않으면 `getGcd(b, a % b)`를 호출해 더 작은 문제로 줄인다.
- 구한 최대공약수를 `gcd`에 저장한다.
- 두 수의 곱을 최대공약수로 나눈 `n * m / gcd`를 최소공배수 `lcm`에 저장한다.
- 최대공약수와 최소공배수를 순서대로 담은 배열을 반환한다.

<br>

### Complexity

---

- Time complexity: `O(log min(n, m))`
  - 유클리드 호제법은 재귀 호출마다 두 번째 인수를 나머지로 줄인다.
  - 최대 두 번의 재귀 호출마다 두 번째 인수가 절반 이하로 감소하므로, `min(n, m)`에서 `0`에 도달하기까지 로그 횟수의 호출이 필요하다. (반복할 때마다 문제의 크기가 일정한 비율로 줄어들면 로그 시간으로 본다.)
  - 최대공약수 계산 이후의 곱셈, 나눗셈, 배열 생성은 각각 상수 시간이다.

- Space complexity: `O(log min(n, m))`
  - 재귀 호출 깊이만큼 호출 스택을 사용한다.

<br>

### Code (Java)

---

```java
class Solution {
    public int[] solution(int n, int m) {
        // 최소공배수는 두 정수의 곱을 최대공약수로 나눈 값이다.
        int gcd = getGcd(n, m);
        int lcm = n * m / gcd;

        return new int[]{gcd, lcm};
    }

    int getGcd(int a, int b) {
        if (b == 0) {
            return a;
        }
        // 유클리드호제법 : a와 b의 최대공약수는 a를 b로 나눈 나머지와 b의 최대공약수이다.
        return getGcd(b, a % b);
    }
}
```

### Code (Python)

---

```python
def solution(n, m):
    # 최소공배수는 두 정수의 곱을 최대공약수로 나눈 값이다.
    # lcm = n * m / gcd
    gcd = getGcd(n, m)
    lcm = n * m / gcd
    return [gcd, lcm]


def getGcd(a, b):
    # 유클리드호제법 : a와 b의 최대공약수는 a를 b로 나눈 나머지와 b의 최대공약수이다.
    if b == 0:
        return a
    return getGcd(b, a % b)
```

- Java 코드와 같이 재귀 유클리드 호제법으로 최대공약수를 구한 뒤 두 수의 곱을 최대공약수로 나눈다.
- Python의 `/` 연산자는 실수 나눗셈이므로 `lcm`은 정수값을 나타내더라도 `float` 타입이 된다.
- 시간 복잡도와 재귀 호출 스택을 포함한 보조 공간 복잡도는 모두 `O(log min(n, m))`이다.
