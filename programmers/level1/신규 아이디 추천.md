### Intuition

---

- 문제에서 요구하는 아이디 변환 규칙은 1단계부터 7단계까지 순서가 정해져 있다.
- 각 단계의 결과가 다음 단계의 입력이 되므로 규칙의 순서를 바꾸거나 일부 단계를 동시에 처리하면 결과가 달라질 수 있다.
- 대소문자 변환, 허용되지 않은 문자 제거, 연속된 마침표 치환처럼 문자열 전체에 적용하는 작업이 중심이다.
- 제거하거나 치환할 문자열의 형태가 명확하므로 정규 표현식을 사용하면 각 규칙을 간결하게 나타낼 수 있다.
- 각 단계를 별도 메서드로 분리하면 문제의 7가지 규칙과 코드가 일대일로 대응되어 처리 과정을 확인하기 쉽다.

<br>

### Approach

---

- `step1`: `toLowerCase()`로 모든 대문자를 소문자로 변환한다.
- `step2`: 정규식 `[^a-z0-9-_.]`에 해당하는 문자를 제거한다.
  - 알파벳 소문자, 숫자, `-`, `_`, `.`만 남는다.
- `step3`: 정규식 `[.]{2,}`로 두 번 이상 연속된 마침표를 하나로 치환한다.
- `step4`: 정규식 `^\\.|\\.$`로 문자열의 처음이나 끝에 있는 마침표를 제거한다.
- `step5`: 문자열이 비어 있으면 `"a"`로 바꾼다.
- `step6`: 길이가 16 이상이면 앞의 15자만 남기고, 잘라낸 문자열의 마지막 문자가 마침표라면 제거한다.
- `step7`: 길이가 2 이하이면 마지막 문자를 필요한 횟수만큼 반복해 길이를 3으로 만든다.
- 각 단계의 반환값을 다음 단계로 전달하고, 7단계를 모두 적용한 문자열을 반환한다.

<br>

### Complexity

---

- Time complexity: `O(n)`
  - `n`은 입력 문자열 `new_id`의 길이이다.
  - 소문자 변환과 정규식 치환은 각각 문자열을 순회하므로 `O(n)`이다.
  - 문자열 전체를 처리하는 단계 수가 7개로 고정되어 있어 전체 시간 복잡도는 `O(7n)`, 즉 `O(n)`이다.

- Space complexity: `O(n)`
  - 문자열은 불변 객체이므로 각 변환 단계에서 결과를 담는 새 문자열이 생성될 수 있다.
  - 단계 수가 고정되어 있으므로 동시에 저장되는 문자열들의 총 크기도 점근적으로 `O(n)`이다.

### Code (Java)

---

```java
class Solution {
    public String solution(String new_id) {

        String id1 = step1(new_id);
        String id2 = step2(id1);
        String id3 = step3(id2);
        String id4 = step4(id3);
        String id5 = step5(id4);
        String id6 = step6(id5);
        String recommandedId = step7(id6);

        return recommandedId;
    }

    private String step1(String id) {
        // 1단계 new_id의 모든 대문자를 대응되는 소문자로 치환합니다.
        return id.toLowerCase();
    }

    private String step2(String id) {
        // 2단계 new_id에서 알파벳 소문자, 숫자, 빼기(-), 밑줄(_), 마침표(.)를 제외한 모든 문자를 제거합니다.
        return id.replaceAll("[^a-z0-9-_.]", "");
    }

    private String step3(String id) {
        // 3단계 new_id에서 마침표(.)가 2번 이상 연속된 부분을 하나의 마침표(.)로 치환합니다.
        return id.replaceAll("[.]{2,}", ".");
    }

    private String step4(String id) {
        // 4단계 new_id에서 마침표(.)가 처음이나 끝에 위치한다면 제거합니다.
        return id.replaceAll("^\\.|\\.$", "");
    }

    private String step5(String id) {
        // 5단계 new_id가 빈 문자열이라면, new_id에 "a"를 대입합니다.
        return id.isEmpty() ? "a" : id;
    }

    private String step6(String id) {
        // 6단계 new_id의 길이가 16자 이상이면, new_id의 첫 15개의 문자를 제외한 나머지 문자들을 모두 제거합니다.
        // 만약 제거 후 마침표(.)가 new_id의 끝에 위치한다면 끝에 위치한 마침표(.) 문자를 제거합니다.
        return id.length() > 15 ? id.substring(0, 15).replaceAll("\\.$", "") : id;
    }

    private String step7(String id) {
        // 7단계 new_id의 길이가 2자 이하라면, new_id의 마지막 문자를 new_id의 길이가 3이 될 때까지 반복해서 끝에 붙입니다.
        int l = id.length();
        return l <= 2 ? id + id.substring(l - 1).repeat(3 - l): id;
    }
}
```

### Code (Python)

---

```python
import re


def solution(new_id):
    result1 = step1(new_id)
    result2 = step2(result1)
    result3 = step3(result2)
    result4 = step4(result3)
    result5 = step5(result4)
    result6 = step6(result5)
    result7 = step7(result6)
    return result7


def step1(s):
    # 모든 대문자를 대응되는 소문자로 치환
    return s.lower()


def step2(s):
    # 알파벳 소문자, 숫자, 빼기(-), 밑줄(_), 마침표(.)를 제외한 모든 문자를 제거
    return re.sub(r'[^a-z0-9\-_\.]', '', s)


def step3(s):
    # 마침표(.)가 2번 이상 연속된 부분을 하나의 마침표(.)로 치환
    return re.sub(r'\.{2,}', '.', s)


def step4(s):
    # 마침표(.)가 처음이나 끝에 위치한다면 제거
    return re.sub(r'^\.|\.+$', '', s)


def step5(s):
    # 빈 문자열이라면, new_id에 "a"를 대입
    if not s:
        return 'a'
    return s


def step6(s):
    # 16자 이상이면, new_id의 첫 15개의 문자를 제외한 나머지 문자들을 모두 제거
    if len(s) > 15:
        sliced = s[:15]
        # 제거 후 마침표(.)가 new_id의 끝에 위치한다면 끝에 위치한 마침표(.) 문자를 제거
        if sliced[-1] == '.':
            return sliced[:14]
        return sliced
    return s


def step7(s):
    # 길이가 2자 이하라면, 마지막 문자를 길이가 3이 될 때까지 반복해서 끝에 붙임
    if len(s) <= 2:
        repeated = s[-1] * (3 - len(s))
        return s + repeated
    return s
```

- 문제의 7가지 변환 규칙을 `step1()`부터 `step7()`까지 별도 함수로 나누어 순서대로 적용한다.
- `lower()`로 소문자 변환을 수행하고, `re.sub()`로 허용되지 않은 문자와 연속된 마침표 등을 처리한다.
- 빈 문자열 처리 후 길이를 최대 15자로 제한하고, 마지막 문자가 마침표이면 제거한다.
- 길이가 2 이하이면 마지막 문자를 반복해 최종 길이를 3으로 만든다.
- 각 단계가 문제의 규칙과 직접 대응하므로 변환 과정을 순서대로 확인하기 쉽다.
- 문자열 전체를 처리하는 단계 수가 고정되어 있으므로 시간 복잡도는 `O(n)`, 공간 복잡도는 `O(n)`이다.
