### Intuition

---

- 문자열 `s`가 `"1"`이 될 때까지 다음 이진 변환을 반복해야 한다.
  - `s`에 포함된 모든 `0`을 제거한다.
  - 남은 문자열의 길이를 이진수로 표현한다.
- 각 변환에서 제거되는 `0`의 수와 변환 횟수를 함께 누적하면 별도의 변환 이력을 저장하지 않고 정답을 구할 수 있다.
- `0`을 제거한 문자열은 모두 `1`로 이루어져 있으므로, 그 문자열의 내용보다 길이만 다음 변환에 필요하다.
- 변환 후 문자열의 길이는 이전보다 빠르게 작아지며, 문제에서 입력은 항상 `1`을 포함하므로 반복하면 최종적으로 `"1"`에 도달한다.

<br>

### Approach

---

- 변환 횟수를 저장할 `translatedCount`와 제거한 `0`의 누적 개수를 저장할 `removedZeroCount`를 `0`으로 초기화한다.
- `s`가 `"1"`이 아닌 동안 다음 작업을 반복한다.
  - `translatedCount`를 `1` 증가시킨다.
  - `s.chars()`로 문자의 정수 스트림을 만들고, `0`인 문자만 필터링하여 그 개수를 `removedZeroCount`에 더한다.
  - `s.replace("0", "")`로 모든 `0`을 제거한 문자열의 길이를 구한다.
  - `Integer.toBinaryString()`으로 해당 길이를 이진 문자열로 변환하여 `s`에 다시 저장한다.
- 반복이 끝나면 변환 횟수와 제거한 `0`의 수를 순서대로 담은 배열을 반환한다.
- 코드에서 선언한 `x`는 이후 연산에 사용되지 않으며 알고리즘의 동작에는 영향을 주지 않는다.

<br>

### Complexity

---

- Time complexity: `O(n)`
  - `n`은 최초 문자열 `s`의 길이이다.
  - 각 반복에서 현재 문자열을 대상으로 `0`의 개수를 세고 `replace()`를 수행하므로 현재 문자열 길이에 비례하는 시간이 든다.
  - 첫 변환 후 문자열 길이는 최대 `n`의 이진 표현 길이인 `O(log n)`으로 줄어든다. 이후 길이도 반복 로그 형태로 감소하므로 모든 반복의 문자열 처리 비용을 합하면 `O(n)`이다.

- Space complexity: `O(n)`
  - 문자 스트림 처리와 `replace()` 및 이진 변환 과정에서 현재 문자열 길이에 비례하는 중간 결과가 생성될 수 있다.
  - 가장 긴 문자열은 최초 입력이므로 동시에 사용하는 보조 공간의 최댓값은 `O(n)`이다.

<br>

### Code (Java)

---

```java
class Solution {
    public int[] solution(String s) {

        int translatedCount = 0;
        int removedZeroCount = 0;

        String x = "";

        while (!s.equals("1")) {
            translatedCount += 1;
            removedZeroCount += (int) s.chars().filter(c -> c == '0').count();

            s = Integer.toBinaryString(s.replace("0", "").length());
        }

        return new int[]{translatedCount, removedZeroCount};
    }
}
```

### Code (Python)

---

```python
def solution(s):
    if s == '1':
        return [0, 0]

    convert_count = 0
    zero_count = 0

    while s != '1':
        convert_count += 1
        zero_count += s.count('0')

        s = s.replace('0', '')
        s = bin(len(s))[2:]

    return [convert_count, zero_count]
```

- `count('0')`으로 제거할 `0`의 수를 누적하고, `replace()`로 `0`을 제거한다.
- `bin(len(s))[2:]`는 남은 `1`의 개수를 접두사 `0b`가 없는 이진 문자열로 변환한다.
- 최초 문자열의 길이를 `n`이라 할 때 시간 복잡도는 `O(n)`, 보조 공간 복잡도는 `O(n)`이다.
