### Intuition

---

- 문자열에는 숫자 문자와 숫자를 나타내는 영단어가 섞여 있다.
- 영단어는 `zero`부터 `nine`까지 10개로 고정되어 있으므로, 각 단어와 숫자의 대응 관계를 미리 저장할 수 있다.
- 문자열을 왼쪽부터 읽으면서 숫자는 바로 결과에 추가하고, 알파벳은 하나의 숫자 영단어가 완성될 때까지 모으면 된다.
- 모은 문자열이 숫자 영단어와 일치하면 대응하는 숫자를 결과에 추가한 뒤 단어 버퍼를 비운다.
- 입력은 항상 올바른 숫자를 표현하고 결과도 정수 범위 안이므로, 완성된 문자열을 `int`로 변환해 반환할 수 있다.

<br>

### Approach

---

- `map`에 숫자 영단어를 key, 대응하는 숫자 문자를 value로 저장한다.
- 변환된 숫자를 저장할 `answer`와 현재 읽고 있는 영단어를 저장할 `word`를 `StringBuilder`로 생성한다.
- 입력 문자열 `s`를 문자 단위로 순회한다.
  - 현재 문자가 숫자이면 `answer`에 바로 추가한다.
  - 알파벳이면 `word`에 추가한다.
  - `word`가 Map의 key와 일치하면 대응하는 숫자를 `answer`에 추가하고 `word`를 비운다.
- 모든 문자를 처리한 뒤 `answer`를 문자열로 변환하고, 다시 `int`로 변환해 반환한다.

<br>

### Complexity

---

- Time complexity: `O(n)`
  - `n`은 문자열 `s`의 길이이다.
  - 입력의 각 문자를 한 번씩 순회한다.
  - `word`의 최대 길이와 숫자 영단어의 수는 고정되어 있으므로 문자열 생성과 해시 조회는 이 문제에서 상수 시간으로 볼 수 있다.

- Space complexity: `O(n)`
  - 변환된 숫자 문자열을 저장하는 `answer`가 입력 길이에 비례할 수 있다.
  - Map에는 항상 10개의 항목만 저장되고 `word`의 길이도 최대 5이므로 해당 공간은 `O(1)`이다.

<br>

### Code (Java)

---

```java
import java.util.Map;

class Solution {
    public int solution(String s) {
        StringBuilder answer = new StringBuilder();
        StringBuilder word = new StringBuilder();

        Map<String, Character> map = Map.of(
            "zero", '0',
            "one", '1',
            "two", '2',
            "three", '3',
            "four", '4',
            "five", '5',
            "six", '6',
            "seven", '7',
            "eight", '8',
            "nine", '9'
        );

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                answer.append(c);
                continue;
            }

            word.append(c);
            String key = word.toString();

            if (map.containsKey(key)) {
                answer.append(map.get(key));
                word.setLength(0);
            }
        }

        return Integer.parseInt(answer.toString());
    }
}
```

### Better Code (Java)

---

```java
class Solution {
    public int solution(String s) {
        String[] words = {
            "zero", "one", "two", "three", "four",
            "five", "six", "seven", "eight", "nine"
        };

        for (int number = 0; number < words.length; number++) {
            s = s.replace(words[number], String.valueOf(number));
        }

        return Integer.parseInt(s);
    }
}
```

- 숫자 영단어를 숫자 순서대로 배열에 저장해 배열 인덱스를 대응하는 숫자로 사용한다.
- `replace()`로 각 영단어를 대응하는 숫자 문자열로 치환한다.
- 숫자 영단어는 10개로 고정되어 있으므로 문자열을 최대 10번 순회하며, 시간 복잡도는 `O(n)`이다.
- 중간에 새 문자열이 생성되므로 공간 복잡도는 `O(n)`이다.
- 문자별 상태와 Map을 직접 관리하지 않아 코드가 짧고 변환 의도가 분명하다.

### Code (Python)

---

```python
def solution(s):
    num_dict = {
        'one': '1', 'two': '2', 'three': '3', 'four': '4', 'five': '5',
        'six': '6', 'seven': '7', 'eight': '8', 'nine': '9', 'zero': '0'
    }
    answer = ''
    char_sum = ''

    for c in s:
        # 숫자이면 answer에 붙인다.
        if c.isdigit():
            answer = answer + c
        # 문자이면
        else:
            # sum에 붙인 후
            char_sum = char_sum + c

            # 정의된 dict에 있으면 해당 숫자를 answer에 붙이고 sum을 초기화한다.
            if char_sum in num_dict:
                answer = answer + num_dict[char_sum]
                char_sum = ''

    return int(answer)
```

- 숫자 영단어와 숫자 문자의 대응 관계를 `num_dict`에 저장한다.
- 입력 문자열을 왼쪽부터 한 문자씩 순회한다.
- 숫자 문자는 `answer`에 바로 추가하고, 알파벳은 `char_sum`에 이어 붙인다.
- `char_sum`이 딕셔너리의 key와 일치하면 대응하는 숫자를 `answer`에 추가하고 `char_sum`을 비운다.
- 모든 문자를 처리한 뒤 완성된 숫자 문자열을 `int`로 변환해 반환한다.
- 시간 복잡도는 일반적으로 문자열 반복 결합 비용 때문에 `O(n^2)`, 공간 복잡도는 `O(n)`이다.
