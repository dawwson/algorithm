### Intuition

---

- 한 번의 명령에서 지나가는 경로에 공원 밖이나 장애물 `X`가 하나라도 포함되면 명령 전체가 취소된다. 도착점만 확인해서는 경로 중간의 문제를 알 수 없으므로 한 칸씩 이동하며 검사해야 한다.
- 잘못된 명령은 시작 전 위치를 유지해야 한다. 현재 좌표를 바로 바꾸지 않고 복사한 좌표에서 이동을 시도한 뒤, 모든 칸이 유효할 때만 현재 좌표를 갱신한다.
- 네 방향의 차이는 행과 열의 변화량뿐이다. 방향별 변화량을 저장하면 같은 로직으로 모든 명령을 처리할 수 있다.

<br>

### Approach

---

1. `park`에서 공원의 가로 길이 `w`와 세로 길이 `h`를 구한다.
2. 방향 문자 `N`, `S`, `W`, `E`를 각각의 행·열 변화량과 연결한 `dirs`를 `Map.of`로 생성한다.
3. 공원을 순회해 시작점 `S`의 좌표를 `curr`에 저장한다.
4. 각 경로에서 방향 `dir`과 거리 `dist`를 구한다.
5. `curr`을 복사한 `temp`에서 한 칸씩 이동한다.
6. 다음 좌표가 범위를 벗어나거나 `X`이면 이동을 중단한다.
7. 유효한 칸이면 `temp`를 이동하고 `dist`를 `1` 줄인다.
8. `dist == 0`이면 `temp`를 `curr`에 반영한다. 거리가 남았다면 해당 명령을 취소한다.
9. 모든 명령을 처리한 뒤 `curr`을 반환한다.

<br>

### Complexity

---

> - `H`: 공원의 세로 길이
> - `W`: 공원의 가로 길이
> - `R`: 이동 명령의 개수
> - `D_i`: `i`번째 명령의 이동 거리

<br>

- Time complexity: `O(H × W + ΣD_i)`
  - 시작점 탐색에 `O(H × W)`, 경로 검사에 `O(ΣD_i)`가 필요하다.
  - `D_i ≤ 9`이므로 제한사항을 적용하면 `O(H × W + R)`이다.

- Space complexity: `O(1)`
  - `dirs`는 항상 네 방향과 길이 2의 좌표 변화량만 저장한다.
  - `curr`과 각 명령에서 생성되는 `temp`도 길이 2의 배열이다.
  - 사용하는 자료구조의 크기가 입력 크기에 따라 증가하지 않으므로 보조 공간은 `O(1)`이다.

<br>

### Code (Java)

---

```java
import java.util.Map;

class Solution {
    public int[] solution(String[] park, String[] routes) {

        int w = park[0].length(); // 공원 가로 길이
        int h = park.length;      // 공원 세로 길이

        int[] curr = new int[2]; // row, col

        // 좌표 변화량
        Map<Character, int[]> dirs = Map.of(
            'N', new int[]{-1, 0},
            'S', new int[]{1, 0},
            'W', new int[]{0, -1},
            'E', new int[]{0, 1}
        );

        // 시작 위치 S 찾기
        for (int i = 0; i < h; i++) {
            for (int j = 0; j < w; j++) {
                if (park[i].charAt(j) == 'S') {
                    curr[0] = i;
                    curr[1] = j;
                }
            }
        }

        // 경로 순회
        for (String route : routes) {
            char dir = route.charAt(0);
            int dist = route.charAt(2) - '0';

            int[] temp = curr.clone();

            while (dist != 0) {
                int x = temp[0] + dirs.get(dir)[0];
                int y = temp[1] + dirs.get(dir)[1];

                boolean isOutOfBounds = x < 0 || x >= h || y < 0 || y >= w;
                if (isOutOfBounds) break;

                boolean isBlocked = park[x].charAt(y) == 'X';
                if (isBlocked) break;

                temp[0] = x;
                temp[1] = y;
                dist -= 1;
            }

            if (dist == 0) {
                curr[0] = temp[0];
                curr[1] = temp[1];
            }
        }

        return curr;
    }
}
```
