> 문제 제목 : 완주하지 못한 선수

### Intuition

---

- 참가자 중 단 한 명만 완주하지 못하며, 동명이인이 있을 수 있으므로 이름의 존재 여부만 저장해서는 각 인원의 완주 여부를 구분할 수 없다.
- 완주자 배열에서 이름별 등장 횟수를 세어 두면 참가자를 확인할 때마다 해당 이름의 남은 완주 횟수를 하나씩 소모할 수 있다.
- 어떤 참가자의 이름에 대응하는 남은 횟수가 `0`이라면 그 참가자는 완주자 명단과 짝지을 수 없는 유일한 선수이다.
- 이름별 남은 완주 횟수를 평균 `O(1)`에 조회하고 갱신하기 위해 `HashMap<String, Integer>`를 사용한다.

<br>

### Approach

---

- 완주자의 이름과 해당 이름의 등장 횟수를 저장할 `HashMap`을 생성한다.
- `completion`을 순회하며 `getOrDefault()`로 기존 횟수를 가져온 뒤 `1`을 더해 저장한다.
- `participant`를 순서대로 순회한다.
  - 참가자 이름의 남은 완주 횟수가 `0`이면 완주하지 못한 선수이므로 `answer`에 저장하고 반복을 종료한다.
  - 남은 횟수가 있으면 그 참가자와 완주 기록 하나를 대응시키고, 맵의 횟수를 `1` 감소시킨다.
- 반복이 끝난 뒤 완주하지 못한 선수의 이름이 저장된 `answer`를 반환한다.

<br>

### Complexity

---

- Time complexity: `O(n)`
  - `n`은 `participant`의 길이이며 `completion`의 길이는 `n - 1`이다.
  - 두 배열을 각각 한 번씩 순회하고, `HashMap`의 조회와 갱신은 평균적으로 `O(1)`이다.

- Space complexity: `O(n)`
  - 최악의 경우 완주자의 이름이 모두 달라 맵에 `n - 1`개의 항목이 저장된다.

<br>

### Code (Java)

---

```java
import java.util.Map;
import java.util.HashMap;

class Solution {
    public String solution(String[] participant, String[] completion) {
        String answer = "";

        Map<String, Integer> map = new HashMap<>();

        for (String c : completion) {
            map.put(c, map.getOrDefault(c, 0) + 1);
        }

        for (String p : participant) {
            if (map.getOrDefault(p, 0) == 0) {
                answer = p;
                break;
            }

            map.put(p, map.get(p) - 1);
        }

        return answer;
    }
}
```

### Code (Python)

---

```python
def solution(participant, completion):
    hashDict = {}
    sumHash = 0

    # 참가자를 모두 딕셔너리(해시테이블)에 넣는다.
    for p in participant:
        hashDict[hash(p)] = p  # key = 해시, value = 참가자 이름
        sumHash += hash(p)     # 해시의 합을 구한다.

    for c in completion:
        sumHash -= hash(c)     # 완주자의 해시를 뺀다.

    return hashDict[sumHash]
```

- 참가자 이름의 해시값을 딕셔너리에 저장하면서 모든 해시값을 더하고, 완주자의 해시값을 차례로 뺀다.
- 마지막에 남은 해시값으로 완주하지 못한 선수의 이름을 조회한다.
- 참가자 수를 `n`이라 할 때 시간 복잡도는 평균 `O(n)`, 보조 공간 복잡도는 `O(n)`이다.
- 서로 다른 이름에서 해시 충돌이 발생하지 않는다는 전제에 의존하는 구현이다.
