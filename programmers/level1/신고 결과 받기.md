### Intuition

---

- 한 사용자가 같은 사용자를 여러 번 신고해도 하나의 신고로만 처리해야 한다.
  - 따라서 전체 신고 문자열을 Set에 넣어 중복을 먼저 제거할 수 있다.
- 정지 여부를 판단하려면 각 사용자가 서로 다른 사용자에게 신고당한 횟수를 알아야 한다.
- 신고당한 횟수가 `k` 이상인 사용자는 정지되며, 그 사용자를 신고한 모든 사용자에게 결과 메일이 발송된다.
- 따라서 중복을 제거한 신고 목록을 두 번 확인하면 된다.
  - 첫 번째 순회에서 사용자별 신고당한 횟수를 센다.
  - 두 번째 순회에서 정지된 사용자를 신고한 사람의 메일 수를 증가시킨다.
- 정답은 `id_list` 순서로 반환해야 하므로 신고자의 위치를 해당 순서에 맞춰 찾아야 한다.

<br>

### Approach

---

- `answer`에 각 사용자가 받을 결과 메일 수를 저장한다.
- `LinkedHashMap`인 `mailCountMap`에 모든 사용자와 초기값 `0`을 저장한다.
  - 이 Map은 이름과 달리 첫 번째 단계에서는 사용자별 신고당한 횟수를 저장한다.
- `report`를 `HashSet`으로 변환해 동일한 신고를 제거한다.
- 중복을 제거한 신고 목록을 처음 순회한다.
  - 신고 문자열을 신고자 `reporter`와 신고당한 사용자 `reported`로 나눈다.
  - `reported`가 신고당한 횟수를 1 증가시킨다.
- 신고 목록을 다시 순회한다.
  - `reported`의 신고당한 횟수가 `k` 이상인지 확인한다.
  - 정지 대상이면 `List.of(id_list).indexOf(reporter)`로 신고자의 인덱스를 찾아 `answer`를 1 증가시킨다.
- 모든 신고를 처리한 뒤 `answer`를 반환한다.

<br>

### Complexity

---

- Time complexity: `O(m * n)`
  - `n`은 `id_list`의 길이, `m`은 `report`의 길이이다.
  - 중복을 제거한 신고 수는 최대 `m`개이다. 신고 목록 순회와 Map 조회는 평균 `O(m)`이지만, 정지된 사용자의 신고마다 `id_list`에서 신고자를 선형 탐색한다.
  - `indexOf()`는 최대 `O(n)`이므로 전체 시간 복잡도는 최악의 경우 `O(m * n)`이다.

- Space complexity: `O(n + m)`
  - 사용자별 횟수를 저장하는 Map에 `n`개, 중복 신고를 저장하는 Set에 최대 `m`개의 항목이 저장된다.
  - 반환 배열은 `O(n)` 공간을 사용한다.

<br>

### Code (Java)

---

```java
import java.util.Map;
import java.util.LinkedHashMap;
import java.util.Set;
import java.util.HashSet;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int[] solution(String[] id_list, String[] report, int k) {
        int[] answer = new int[id_list.length];
        Map<String, Integer> mailCountMap = new LinkedHashMap<>();
        Set<String> reportSet = new HashSet<>(Arrays.asList(report));

        for (String id : id_list) {
            mailCountMap.put(id, 0);
        }

        reportSet.forEach((r) -> {
            String[] splitted = r.split(" ");
            String reported = splitted[1];
            int count = mailCountMap.get(reported);

            mailCountMap.put(reported, count + 1);
        });

        reportSet.forEach((r) -> {
            String[] splitted = r.split(" ");
            String reporter = splitted[0];
            String reported = splitted[1];
            int count = mailCountMap.get(reported);
            boolean banned = count >= k;

            if (banned) {
                int reporterIndex = List.of(id_list).indexOf(reporter);
                answer[reporterIndex] += 1;
            }
        });

        return answer;
    }
}
```

### Better Code (Java)

---

```java
import java.util.HashSet;
import java.util.HashMap;
import java.util.Map;
import java.util.Set;

class Solution {
    public int[] solution(String[] id_list, String[] report, int k) {
        int userCount = id_list.length;
        int[] answer = new int[userCount];
        Map<String, Integer> indexById = new HashMap<>();
        Map<String, Integer> reportedCount = new HashMap<>();

        for (int i = 0; i < userCount; i++) {
            indexById.put(id_list[i], i);
        }

        Set<String> uniqueReports = new HashSet<>();

        for (String entry : report) {
            if (!uniqueReports.add(entry)) {
                continue;
            }

            String reported = entry.substring(entry.indexOf(' ') + 1);
            reportedCount.merge(reported, 1, Integer::sum);
        }

        for (String entry : uniqueReports) {
            int separator = entry.indexOf(' ');
            String reporter = entry.substring(0, separator);
            String reported = entry.substring(separator + 1);

            if (reportedCount.get(reported) >= k) {
                answer[indexById.get(reporter)]++;
            }
        }

        return answer;
    }
}
```

- 사용자 ID별 인덱스를 `indexById`에 미리 저장해 신고자의 위치를 평균 `O(1)`에 찾는다.
- `HashSet.add()`의 반환값으로 중복 신고 여부를 확인하면서 신고당한 횟수를 함께 계산한다.
- `reportedCount.merge()`를 사용해 신고당한 횟수를 간결하게 누적한다.
- 공백의 위치를 기준으로 `substring()`을 사용해 신고자와 신고당한 사용자를 구한다.
- 시간 복잡도는 평균 `O(n + m)`, 공간 복잡도는 `O(n + m)`이다.

### Code (Python)

---

```python
def solution(id_list, report, k):
    answer = [0] * len(id_list)
    # 신고된 아이디: 신고된 횟수
    reported_list = {x: 0 for x in id_list}

    # 중복 신고 제거하기 위해 set 사용
    for r in set(report):
        reporter, reported = r.split()
        reported_list[reported] += 1

    for r in set(report):
        reporter, reported = r.split()

        if reported_list[reported] >= k:
            answer[id_list.index(reporter)] += 1

    return answer
```

- `reported_list`에 사용자별 신고당한 횟수를 저장한다.
- `set(report)`로 동일한 사용자가 같은 사용자를 여러 번 신고한 내역을 제거한다.
- 첫 번째 순회에서 신고당한 사용자의 횟수를 1씩 증가시킨다.
- 두 번째 순회에서 신고당한 횟수가 `k` 이상인 사용자를 확인한다.
- 정지된 사용자를 신고한 사람의 인덱스를 `id_list.index()`로 찾아 메일 수를 증가시킨다.
- `id_list.index()`가 선형 탐색을 수행하므로 시간 복잡도는 최악의 경우 `O(m * n)`, 공간 복잡도는 `O(n + m)`이다.
