### Intuition

---

- 세 수포자가 답을 찍는 방식은 각각 일정한 패턴을 반복한다.
- 문제 번호 `i`에서 각 수포자가 선택한 답은 `i % pattern.length`를 이용해 구할 수 있다.
- 각 문제의 정답과 세 수포자의 답을 모두 비교하면 각자의 점수를 계산할 수 있다.
- 수포자는 3명뿐이고 `answers`의 길이도 최대 10,000이므로, 모든 문제를 직접 비교하는 완전탐색으로 충분하다.
- 최고 점수를 받은 사람이 여러 명이면 모두 반환해야 하며, 오름차순으로 반환해야 한다.
  - 점수 배열을 1번 수포자부터 순서대로 확인하면 별도의 정렬 없이 오름차순 결과를 만들 수 있다.

<br>

### Approach

---

- 세 수포자의 반복 답안 패턴을 각각 `pattern1`, `pattern2`, `pattern3` 배열에 저장한다.
- 세 수포자의 점수를 저장할 길이 3의 `score` 배열을 생성한다.
- `answers`를 처음부터 끝까지 순회한다.
  - 현재 문제 번호를 각 패턴 길이로 나눈 나머지를 인덱스로 사용한다.
  - 실제 정답과 수포자의 패턴 값이 같으면 해당 수포자의 점수를 1 증가시킨다.
- `getMax(score)`로 세 점수 중 최댓값을 구한다.
- 점수 배열을 앞에서부터 확인하며 최고 점수와 같은 수포자의 번호 `i + 1`을 `result`에 추가한다.
- `result`를 `int[]`로 변환해 반환한다.

<br>

### Complexity

---

- Time complexity: `O(n)`
  - `n`은 `answers`의 길이이다.
  - 각 문제마다 세 수포자의 답을 비교하며, 수포자 수 3은 고정된 상수이다.
  - 최고 점수 탐색과 결과 생성도 길이 3의 배열만 확인하므로 상수 시간이다.

- Space complexity: `O(1)`
  - 세 답안 패턴과 점수 배열의 크기는 입력 크기와 관계없이 일정하다.
  - 결과에도 최대 3명의 번호만 저장된다.

<br>

### Code (Java)

---

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] solution(int[] answers) {

        int[] pattern1 = new int[] {1, 2, 3, 4, 5};
        int[] pattern2 = new int[] {2, 1, 2, 3, 2, 4, 2, 5};
        int[] pattern3 = new int[] {3, 3, 1, 1, 2, 2, 4, 4, 5, 5};

        int[] score = new int[] {0, 0, 0};
        List<Integer> result = new ArrayList<>();

        for (int i = 0; i < answers.length; i++) {
            if (answers[i] == pattern1[i % pattern1.length]) {
                score[0] += 1;
            }
            if (answers[i] == pattern2[i % pattern2.length]) {
                score[1] += 1;
            }
            if (answers[i] == pattern3[i % pattern3.length]) {
                score[2] += 1;
            }
        }

        int max = getMax(score);

        for (int i = 0; i < score.length; i++) {
            if (max == score[i]) {
                result.add(i + 1);
            }
        }

        return result.stream()
                .mapToInt(Integer::intValue)
                .toArray();
    }

    public int getMax(int[] arr) {
        int max = arr[0];

        for (int i = 0; i < arr.length; i++) {
            max = Math.max(max, arr[i]);
        }

        return max;
    }
}
```

### Better Code (Java)

---

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] solution(int[] answers) {
        int[] pattern1 = {1, 2, 3, 4, 5};
        int[] pattern2 = {2, 1, 2, 3, 2, 4, 2, 5};
        int[] pattern3 = {3, 3, 1, 1, 2, 2, 4, 4, 5, 5};
        int[] scores = new int[3];

        for (int i = 0; i < answers.length; i++) {
            if (answers[i] == pattern1[i % pattern1.length]) scores[0]++;
            if (answers[i] == pattern2[i % pattern2.length]) scores[1]++;
            if (answers[i] == pattern3[i % pattern3.length]) scores[2]++;
        }

        int maxScore = Math.max(scores[0], Math.max(scores[1], scores[2]));
        List<Integer> winners = new ArrayList<>();

        for (int i = 0; i < scores.length; i++) {
            if (scores[i] == maxScore) {
                winners.add(i + 1);
            }
        }

        return winners.stream()
                .mapToInt(Integer::intValue)
                .toArray();
    }
}
```

- 수포자가 항상 3명이라는 문제 조건에 맞춰 각 패턴을 별도 배열로 두어 비교 과정을 직관적으로 표현한다.
- 별도의 `getMax()` 메서드 없이 `Math.max()`로 세 점수의 최댓값을 바로 구한다.
- 점수 배열을 수포자 번호 순서대로 확인하므로 별도의 정렬 없이 오름차순 결과를 만든다.
- 성능을 바꾸기보다는 기존 코드의 구조를 유지하면서 불필요한 메서드를 줄인 리팩터링이다.
- 시간 복잡도는 `O(n)`, 공간 복잡도는 `O(1)`로 기존 코드와 동일하다.

### Code (Python)

---

```python
def solution(answers):
    # 각 수포자의 정답 패턴을 저장한 배열
    pattern1 = [1, 2, 3, 4, 5]
    pattern2 = [2, 1, 2, 3, 2, 4, 2, 5]
    pattern3 = [3, 3, 1, 1, 2, 2, 4, 4, 5, 5]

    scores = [0, 0, 0]
    result = []

    for index, answer in enumerate(answers):
        # 패턴의 길이만큼 끊어서 정답을 체크한다.
        if answer == pattern1[index % len(pattern1)]:
            scores[0] += 1
        if answer == pattern2[index % len(pattern2)]:
            scores[1] += 1
        if answer == pattern3[index % len(pattern3)]:
            scores[2] += 1

    # 가장 많이 맞춘 학생들만 저장한 배열을 반환한다.
    for index, score in enumerate(scores):
        if score == max(scores):
            result.append(index + 1)
    return result
```

- 세 수포자의 반복 답안 패턴을 각각 `pattern1`, `pattern2`, `pattern3`에 저장한다.
- `enumerate(answers)`로 문제의 인덱스와 실제 정답을 함께 순회한다.
- 문제 인덱스를 각 패턴 길이로 나눈 나머지를 사용해 해당 문제에서 수포자가 선택한 답을 구한다.
- 실제 정답과 패턴의 답이 같으면 해당 수포자의 점수를 1 증가시킨다.
- 점수 배열을 수포자 번호 순서대로 확인하며 최고 점수와 같은 사람을 `result`에 추가한다.
- 수포자 번호 순서대로 추가하므로 결과는 자동으로 오름차순이 된다.
- 시간 복잡도는 `O(n)`, 공간 복잡도는 `O(1)`이다.
