### Intuition

---

- 크레인은 선택한 열에서 가장 위에 있는 인형 하나만 뽑으므로, 각 이동마다 해당 열을 위쪽 행부터 확인해야 한다.
- 인형을 뽑은 칸을 `0`으로 바꾸면 이후 이동에서도 현재 보드 상태를 그대로 이용할 수 있다.
- 바구니에서는 새 인형과 가장 위의 인형만 비교하며, 두 인형이 같으면 둘 다 사라진다.
- 따라서 바구니는 마지막에 넣은 값을 먼저 확인하고 제거하는 스택처럼 동작한다.
- `ArrayList`의 마지막 원소를 스택의 맨 위로 사용하면 인형 추가와 마지막 인형 제거를 처리할 수 있다.

<br>

### Approach

---

- 뽑은 인형을 저장할 `basket`과 사라진 인형 수를 저장할 `count`를 초기화한다.
- `moves`를 순서대로 순회한다.
  - 문제의 열 번호는 `1`부터 시작하므로 `move - 1`을 계산해 배열 인덱스 `col`로 사용한다.
  - 선택한 열을 `0`번 행부터 아래로 탐색해 값이 `0`이 아닌 첫 번째 칸을 찾는다.
  - 인형을 찾으면 해당 칸을 `0`으로 바꾸어 보드에서 제거한다.
  - `basket`이 비어 있지 않고 마지막 인형이 방금 뽑은 인형과 같으면 마지막 인형을 제거하고 `count`를 `2` 증가시킨다.
  - 두 인형이 다르면 뽑은 인형을 `basket`의 마지막에 추가한다.
  - 한 번의 이동에서는 인형을 하나만 뽑으므로 현재 열 탐색을 종료한다.
- 모든 이동을 처리한 뒤 사라진 인형의 총개수 `count`를 반환한다.

<br>

### Complexity

---

- Time complexity: `O(m * n)`
  - `n`은 정사각형 보드의 한 변 길이이고, `m`은 `moves`의 길이이다.
  - 각 이동마다 선택한 열을 위에서부터 최대 `n`칸 탐색한다.
  - 바구니의 마지막 원소 조회, 추가와 제거는 각각 `O(1)` 또는 분할 상환 `O(1)`이다.

- Space complexity: `O(m)`
  - 이동마다 최대 한 개의 인형이 바구니에 추가되므로 최악의 경우 `m`개의 인형을 저장한다.
  - 입력으로 받은 `board`를 직접 수정하므로 별도의 보드 복사 공간은 사용하지 않는다.

<br>

### Code (Java)

---

```java
import java.util.List;
import java.util.ArrayList;

class Solution {
    public int solution(int[][] board, int[] moves) {

        List<Integer> basket = new ArrayList<>();

        int count = 0;
        int n = board.length;

        for (int move : moves) {
            int col = move - 1;

            for (int row = 0; row < n; row++) {
                int pick = board[row][col];

                if (pick != 0) {
                    board[row][col] = 0;
                    int topIndex = basket.size() - 1;

                    if (!basket.isEmpty() && basket.get(topIndex) == pick) {
                        basket.remove(topIndex);
                        count += 2;
                    } else {
                        basket.add(pick);
                    }

                    break;
                }
            }
        }

        return count;
    }
}
```

### Code (Python)

---

```python
def solution(board, moves):
    count = 0
    basket = []

    for move in moves:
        for row in range(len(board)):
            pick = board[row][move-1]

            if pick != 0:
                if len(basket) != 0 and basket[-1] == pick:
                    basket.pop()
                    count += 2
                else:
                    basket.append(pick)
                board[row][move-1] = 0
                break

    return count
```

- Python 리스트의 마지막 원소를 바구니의 맨 위로 사용하고 `append()`와 `pop()`으로 스택 동작을 구현한다.
- 각 이동에서 선택한 열의 첫 번째 인형을 찾은 뒤 보드에서 제거하며, 같은 인형이 연속되면 두 개를 없앤다.
- 보드 한 변을 `n`, 이동 횟수를 `m`이라 할 때 시간 복잡도는 `O(mn)`, 보조 공간 복잡도는 `O(m)`이다.
