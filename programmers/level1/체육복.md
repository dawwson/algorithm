### Intuition

---

- 학생은 바로 앞번호나 뒷번호의 학생에게만 체육복을 빌릴 수 있다.
- 여벌 체육복을 가져온 학생도 도난당할 수 있으므로, 도난과 여벌 정보를 따로 판단하기보다 학생별 실제 체육복 수량을 계산해야 한다.
- 모든 학생이 처음에 체육복을 한 벌씩 가지고 있다고 두고 도난당하면 `-1`, 여벌이 있으면 `+1`을 적용하면 각 학생의 수량은 `0`, `1`, `2` 중 하나가 된다.
- 번호가 작은 학생부터 확인하면서 체육복이 없을 때 앞번호 학생에게 먼저 빌리고, 불가능하면 뒷번호 학생에게 빌린다.
  - 어떤 이웃에게 먼저 빌릴지를 매 순간 결정하는 부분이 탐욕법에 해당한다.
    1. 앞번호 학생의 여벌을 우선 사용한다.
    2. 앞번호에게 빌릴 수 없으면 뒷번호 학생에게 빌린다.
    3. 한 번 내린 대여 결정을 되돌리지 않는다.

- 앞번호 학생은 현재 학생보다 먼저 검사되었으므로 체육복이 남아 있다면 이후에는 빌려줄 대상이 없다. 따라서 앞번호 학생의 여벌을 우선 사용해도 이후 선택을 방해하지 않는다.

<br>

### Approach

---

- 인덱스를 학생 번호와 일치시키기 위해 크기가 `n + 1`인 `student` 배열을 만들고 모든 값을 `1`로 채운다.
- `lost`를 순회하며 도난당한 학생의 체육복 수량을 `1` 감소시킨다.
- `reserve`를 순회하며 여벌이 있는 학생의 체육복 수량을 `1` 증가시킨다.
  - 같은 학생이 두 배열에 모두 포함되면 두 연산이 상쇄되어 체육복 한 벌을 가진 상태가 된다.
- `1`번 학생부터 `n`번 학생까지 차례로 확인한다.
  - 현재 학생의 체육복 수량이 `0`이고 앞번호 학생이 두 벌을 가지고 있으면 앞번호 학생에게 한 벌을 빌린다.
  - 앞번호 학생에게 빌릴 수 없다면 뒷번호 학생이 두 벌을 가지고 있는지 확인하고 한 벌을 빌린다.
  - 대여 처리 후 현재 학생의 체육복 수량이 `1` 이상이면 수업을 들을 수 있으므로 `answer`를 `1` 증가시킨다.
- 모든 학생을 확인한 뒤 수업을 들을 수 있는 학생 수를 반환한다.

<br>

### Complexity

---

- Time complexity: `O(n)`
  - `n`은 전체 학생 수이다.
  - `student` 배열 초기화, `lost`와 `reserve` 처리, 전체 학생 순회에 각각 선형 시간이 필요하다.
  - `lost`와 `reserve`의 길이는 최대 `n`이므로 전체 시간 복잡도는 `O(n)`이다.

- Space complexity: `O(n)`
  - 학생별 체육복 수량을 저장하는 길이 `n + 1`의 배열을 사용한다.

<br>

### Code (Java)

---

```java
import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

class Solution {
    public int solution(int n, int[] lost, int[] reserve) {
        int answer = 0;

        // 체육복 개수 -> 1로 초기화
        int[] student = new int[n + 1];
        Arrays.fill(student, 1);

        // 도난 처리
        for (int l : lost) {
            student[l] -= 1;
        }

        // 여벌 처리
        for (int r : reserve) {
            student[r] += 1;
        }

        for (int i = 1; i <= n; i++) {
            // 체육복이 없는 경우
            if (student[i] == 0) {
                // 앞번호 학생에게 빌릴 수 있는 경우
                if (i > 1 && student[i - 1] == 2) {
                    student[i] += 1;
                    student[i-1] -= 1;
                }
                // 뒷번호 학생에게 빌릴 수 있는 경우
                else if (i < n && student[i + 1] == 2) {
                    student[i] += 1;
                    student[i + 1] -= 1;
                }
            }

            // 체육복이 있는 학생이면 수업 가능
            if (student[i] > 0) {
                answer += 1;
            }
        }

        return answer;
    }
}
```

### Code (Python)

---

```python
def solution(n, lost, reserve):
    # 여분의 체육복이 있는 학생 중 도난 당하지 않은 학생
    _reserve = [r for r in reserve if r not in lost]
    _reserve.sort()
    # 도난 당한 학생 중 여분의 체육복이 없는 학생
    _lost = [l for l in lost if l not in reserve]
    _lost.sort()

    # 빌려줄 수 있는 학생 기준으로 loop 진행
    for r in _reserve:
        # 앞 번호
        f = r - 1
        # 뒷 번호
        b = r + 1
        # 앞 번호가 도난 당한 학생이면 빌려줌
        if f in _lost:
            _lost.remove(f)
        # 뒷 번호가 도난 당한 학생이면 빌려줌
        elif b in _lost:
            _lost.remove(b)
    return n - len(_lost)
```

- 두 리스트의 차집합을 만들어 여벌 체육복을 도난당한 학생을 대여 대상에서 미리 제외한다.
- 정렬된 여벌 학생을 순회하며 앞번호의 도난 학생을 우선 찾고, 없으면 뒷번호 학생에게 빌려준다.
- 리스트의 `in`과 `remove()`가 선형 시간이므로 학생 수를 `n`이라 할 때 최악의 시간 복잡도는 `O(n²)`, 추가 리스트에 필요한 보조 공간 복잡도는 `O(n)`이다.
