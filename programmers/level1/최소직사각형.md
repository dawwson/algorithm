### Intuition

---

- 모든 명함을 수납하려면 지갑의 가로와 세로가 각 명함의 두 변을 모두 포함할 수 있어야 한다.
- 명함은 회전할 수 있으므로 입력된 가로와 세로의 방향을 그대로 유지할 필요가 없다.
- 각 명함의 긴 변을 한 방향에, 짧은 변을 다른 방향에 놓도록 방향을 통일하면 가능한 배치를 일관되게 비교할 수 있다.
- 통일된 긴 변 중 최댓값과 짧은 변 중 최댓값이 모든 명함을 담기 위해 필요한 두 변의 최소 길이이다.
- 따라서 각 명함의 두 변을 큰 값과 작은 값으로 구분한 뒤 각 그룹의 최댓값을 구한다.

<br>

### Approach

---

- 각 명함의 긴 변을 저장할 `maxSizes`와 짧은 변을 저장할 `minSizes`를 생성한다.
- `sizes`를 순회하며 각 명함의 가로 `w`와 세로 `h`를 비교한다.
  - `w > h`이면 `w`를 `maxSizes`에, `h`를 `minSizes`에 추가한다.
  - 그렇지 않으면 `h`를 `maxSizes`에, `w`를 `minSizes`에 추가한다.
- `Collections.max(maxSizes)`로 모든 긴 변을 포함할 길이를 구한다.
- `Collections.max(minSizes)`로 모든 짧은 변을 포함할 길이를 구한다.
- 두 최댓값을 곱해 모든 명함을 수납할 수 있는 지갑의 최소 넓이를 반환한다.

<br>

### Complexity

---

- Time complexity: `O(n)`
  - `n`은 `sizes`에 포함된 명함의 수이다.
  - 모든 명함을 한 번 순회해 두 리스트를 만들고, `Collections.max()`가 각 리스트를 한 번씩 순회한다.

- Space complexity: `O(n)`
  - 각 명함의 긴 변과 짧은 변을 `maxSizes`와 `minSizes`에 각각 저장한다.

<br>

### Code (Java)

---

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Collections;

class Solution {
    public int solution(int[][] sizes) {

        List<Integer> maxSizes = new ArrayList<>();
        List<Integer> minSizes = new ArrayList<>();

        for (int[] size : sizes) {
            int w = size[0];
            int h = size[1];

            if (w > h) {
                maxSizes.add(w);
                minSizes.add(h);
            } else {
                maxSizes.add(h);
                minSizes.add(w);
            }
        }

        return Collections.max(maxSizes) * Collections.max(minSizes);
    }
}
```

### Better Code (Java)

---

```java
class Solution {
    public int solution(int[][] sizes) {
        int maxLongSide = 0;
        int maxShortSide = 0;

        for (int[] size : sizes) {
            maxLongSide = Math.max(maxLongSide, Math.max(size[0], size[1]));
            maxShortSide = Math.max(maxShortSide, Math.min(size[0], size[1]));
        }

        return maxLongSide * maxShortSide;
    }
}
```

- 각 명함의 긴 변과 짧은 변을 리스트에 모두 저장하지 않고, 순회 중 두 최댓값만 갱신한다.
- 시간 복잡도는 원본과 같은 `O(n)`이고, 보조 공간 복잡도는 `O(n)`에서 `O(1)`로 개선된다.

<br>

### Code (Python)

---

```python
def solution(sizes):
    max_list = []
    min_list = []

    # 명함을 회전시킬 수 있으므로 긴 쪽/짧은 쪽을 나눠서 배열에 저장한다.
    for s in sizes:
        max_list.append(max(s))
        min_list.append(min(s))

    # 긴 쪽 중에 최댓값 * 짧은 쪽 중에 최댓값이 지갑의 최소 크기이다.
    return max(max_list) * max(min_list)
```

- 각 명함에서 `max(s)`와 `min(s)`로 긴 변과 짧은 변을 구분하여 별도 리스트에 저장한다.
- 두 리스트의 최댓값을 곱해 모든 명함을 담을 수 있는 지갑의 최소 넓이를 구한다.
- 명함 수를 `n`이라 할 때 시간 복잡도는 `O(n)`, 보조 공간 복잡도는 `O(n)`이다.
