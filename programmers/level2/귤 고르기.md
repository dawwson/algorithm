### Intuition

---

- 귤 `k`개를 골랐을 때 포함되는 서로 다른 크기의 수를 최소화하는 문제이다.
- 같은 크기의 귤은 몇 개를 선택하더라도 종류 수를 `1`만 증가시킨다. 따라서 한 종류를 선택할 때 가능한 한 많은 귤을 가져오는 것이 유리하다. 따라서 각 크기의 귤이 몇 개씩 있는지 먼저 세고, 개수가 많은 크기부터 선택하는 **그리디 알고리즘**을 사용한다.
  - 예를 들어 크기별 개수가 `[5, 3, 2, 1]`이고 `k = 7`이라면, `5개`와 `3개`인 종류를 차례로 선택하면 두 종류만으로 `7개` 이상을 채울 수 있다.
- 크기별 개수를 빠르게 집계하기 위해 `HashMap`을 사용하고, 빈도만 내림차순으로 정렬해 선택 순서를 정한다.

<br>

### Approach

---

- 귤의 크기를 키로, 해당 크기의 개수를 값으로 저장할 `HashMap`을 생성한다.
- `tangerine`을 순회하며 `getOrDefault()`로 크기별 개수를 누적한다.
- `map.values()`를 복사하여 크기별 개수만 담은 `counts` 리스트를 만든다.
- `counts`를 내림차순으로 정렬하여 개수가 많은 종류부터 확인할 수 있게 한다.
- 지금까지 선택한 귤 수 `sum`과 선택한 종류 수 `type`을 `0`으로 초기화한다.
- 정렬된 `counts`를 앞에서부터 순회한다.
  - 현재 종류의 귤 개수를 `sum`에 더한다.
  - 한 종류를 선택했으므로 `type`을 `1` 증가시킨다.
  - `sum`이 `k` 이상이면 필요한 귤 수를 채웠으므로 반복을 종료한다.
- 선택한 최소 종류 수 `type`을 반환한다.

<br>

### Complexity

---

- Time complexity: `O(n log n)`
  - tangerine의 길이를 n이라고 할 때 tangerine 순회 → `O(n)`

    최악의 경우 모든 귤의 크기가 다르다고 할 때 Map의 크기도 `n`이다.

    counts를 내림차순으로 정렬 → `O(n log n)`

    counts를 순회 → `O(n)`

  - 종합하면 `O(n + n log n)`이고, 낮은 차수의 항을 생략하면 `O(n log n)`이다.

- Space complexity: `O(n)`
  - map, counts의 길이는 최악의 경우 tangerine과 같은 `n`이므로 `O(n)`이다.

### Code (Java)

---

```java
import java.util.Map;
import java.util.HashMap;
import java.util.List;
import java.util.ArrayList;
import java.util.Collections;

class Solution {
    public int solution(int k, int[] tangerine) {
        Map<Integer, Integer> map = new HashMap<>();

        for (int t : tangerine) {
            map.put(t, map.getOrDefault(t, 0) + 1);
        }

        // 개수가 많은 것부터 골라야 종류를 최소화할 수 있다.
        // Map value만 내림차순으로 정렬된 List 생성
        List<Integer> counts = new ArrayList<>(map.values());
        counts.sort(Collections.reverseOrder());

        int sum = 0;
        int type = 0;

        for (int count : counts) {
            sum += count;
            type += 1;

            if (sum >= k) break;
        }

        return type;
    }
}
```

### Code (Python)

---

```python
from collections import Counter


def solution(k, tangerine):
    # {key: 사이즈, value: 개수}인 딕셔너리를 value 기준 내림차순 정렬
    sorted_items = sorted(Counter(tangerine).items(), key=lambda x: x[1], reverse=True)
    t_dict = dict(sorted_items)

    type_count = 0

    for size, count in t_dict.items():
        # 귤 개수를 채웠으면 종료
        if k <= 0:
            break
        # 한 종류로 귤 개수를 채울 수 있는 경우
        if count > k and type_count == 0:
            return 1

        k -= count
        type_count += 1

    return type_count
```

- `Counter`로 크기별 개수를 센 뒤, `(크기, 개수)` 항목을 개수 기준 내림차순으로 정렬한다.
- 정렬 결과를 다시 딕셔너리로 만들고 개수가 많은 크기부터 `k`에서 빼면서 선택한 종류 수를 센다.
