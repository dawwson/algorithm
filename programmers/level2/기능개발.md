### Intuition

---

- 각 기능이 완료되는 날짜는 남은 진행률을 하루 작업 속도로 나누어 구할 수 있다.
- 기능은 앞에서부터 배포한다. 뒤 기능이 먼저 완료되어도 앞 기능의 완료일까지 기다렸다가 함께 배포된다.
- 현재 배포 묶음의 기준일보다 일찍 또는 같은 날 완료되는 기능은 같은 묶음에 포함한다.
- 기준일보다 늦게 완료되는 기능을 만나면 새로운 배포 묶음을 시작하고 그 날짜를 새 기준일로 삼는다.
- 먼저 들어온 기능을 먼저 처리하는 FIFO 구조이므로 큐의 성질과 같으나 문제 풀이에서는 사실상 사용하지 않는다.

<br>

### Approach

---

1. 각 기능의 남은 진행률 `100 - progress`를 작업 속도 `speed`로 나눈 뒤 올림하여 완료일을 구한다.
2. 완료일을 순서대로 `days`에 저장한다.
3. `days`를 앞에서부터 순회하며 현재 배포 묶음의 기준일을 `hold`로 관리한다.
4. 완료일이 `hold` 이하이면 앞 기능과 함께 배포하므로 마지막 배포 개수를 `1` 증가시킨다.
5. 완료일이 `hold`보다 크면 새로운 배포 묶음을 추가하고 `hold`를 해당 완료일로 갱신한다.
6. 배포 개수 목록을 `int[]`로 변환해 반환한다.

<br>

### Complexity

---

> `N`: 기능의 개수

- Time complexity: `O(N)`
  - 완료일 계산과 배포 묶음 계산에서 기능을 각각 한 번씩 순회한다.
  - 결과 리스트를 배열로 변환하는 비용도 `O(N)`이다.

- Space complexity: `O(N)`
  - 완료일을 저장하는 `days`와 배포 개수를 저장하는 `features`가 입력 크기에 비례한다.

<br>

### Code (Java)

---

```java
import java.util.List;
import java.util.ArrayList;

class Solution {
    public int[] solution(int[] progresses, int[] speeds) {

        List<Integer> days = new ArrayList<>();

        for (int i = 0; i < progresses.length; i++) {
            int progress = progresses[i];
            int speed = speeds[i];

            int day = (int) Math.ceil((double) (100 - progress) / speed);
            days.add(day);
        }

        List<Integer> features = new ArrayList<>();
        int hold = 0;

        for (int day : days) {
            if (day <= hold) {
                int lastIndex = features.size() - 1;
                int count = features.get(lastIndex);
                features.set(lastIndex, count + 1);
            } else {
                features.add(1);
                hold = day;
            }
        }

        return features.stream()
            .mapToInt(Integer::intValue)
            .toArray();
    }
}
```

### Code (Python)

---

```python
import math

def solution(progresses, speeds):
    days = []

    for progress, speed in zip(progresses, speeds):
        day = math.ceil((100 - progress) / speed)
        days.append(day)

    front = 0
    deploy_cnt = []

    for day in days:
        if not deploy_cnt or day > front:
            deploy_cnt.append(1)
            front = day
        else:
            deploy_cnt[-1] += 1

    return deploy_cnt
```

- `zip()`으로 진행률과 속도를 함께 순회하고 `math.ceil()`로 완료일을 계산한다.
- `deploy_cnt[-1]`로 현재 배포 묶음의 개수를 갱신한다.
- 시간 복잡도와 보조 공간 복잡도는 모두 `O(N)`이다.

### Code (C++)

---

```cpp
#include <cmath>
#include <vector>

using namespace std;

vector<int> Solution(vector<int> progresses, vector<int> speeds) {
    vector<int> days;

    for (int i = 0; i < progresses.size(); i++) {
        int progress = progresses[i];
        int speed = speeds[i];

        int day = static_cast<int>(ceil(static_cast<double>(100 - progress) / speed));
        days.push_back(day);
    }

    vector<int> features;
    int hold = 0;

    for (int day : days) {
        if (day <= hold) {
            features.back() += 1;
        } else {
            features.push_back(1);
            hold = day;
        }
    }

    return features;
}
```

- `vector<int>`는 Java의 `List<Integer>`와 같은 용도로 완료일과 배포 개수를 저장한다. `push_back()`으로 원소를 추가하고 `back()`으로 마지막 원소에 접근한다.
- `<cmath>`의 `ceil()`로 나눗셈 결과를 올림한다. 정수 나눗셈을 피하기 위해 `static_cast<double>()`로 피연산자를 실수로 변환하고, 결과는 `static_cast<int>()`로 정수로 변환한다.
- 범위 기반 `for (int day : days)`로 `days`의 원소를 순서대로 순회한다.
