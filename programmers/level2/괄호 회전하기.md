### Intuition

---

- 문자열 길이가 `N`이면 왼쪽으로 `0`칸부터 `N - 1`칸까지 옮긴 총 `N`가지 회전 결과가 나온다. `N`은 최대 1,000이므로 각 결과를 직접 만들어 검증할 수 있다.
- 회전한 문자열이 올바른지 확인하려면 여는 괄호를 저장하고, 닫는 괄호를 만났을 때 가장 최근의 여는 괄호와 짝이 맞는지 검사해야 한다.
- 가장 최근에 저장한 괄호부터 확인하므로 스택을 사용한다.

<br>

### Approach

---

1. `substring()`으로 문자열을 한 칸씩 왼쪽으로 회전한다.
2. 회전한 문자열을 앞에서부터 순회한다.
3. 여는 괄호는 `stack`에 넣는다.
4. 닫는 괄호를 만났을 때 스택이 비어 있거나 맨 위 괄호와 짝이 맞지 않으면 올바르지 않은 문자열로 판단한다.
5. 짝이 맞으면 스택의 맨 위 괄호를 제거한다.
6. 문자열을 모두 확인한 뒤 스택이 비어 있으면 올바른 회전의 개수를 증가시킨다.

<br>

### Complexity

---

> `N`: 문자열 `s`의 길이

- Time complexity: `O(N²)`
  - `N`개의 회전을 만들고 각 회전마다 최대 `N`개의 괄호를 검사한다.
  - 회전 문자열을 생성하는 `substring()`과 문자열 연결에도 회전마다 `O(N)`이 필요하다.

- Space complexity: `O(N)`
  - 회전 문자열과 `validate()`의 지역 스택에 각각 최대 `N`개의 문자를 저장한다.

<br>

### Code (Java)

---

```java
import java.util.Deque;
import java.util.ArrayDeque;

class Solution {

    public int solution(String s) {
        if (s.length() == 1) {
            return 0;
        }

        int answer = 0;

        for (int i = 1; i <= s.length(); i++) {
            // 1. 회전
            String rotated = s.substring(i) + s.substring(0, i);

            // 2. 검증
            boolean valid = validate(rotated);

            if (valid) {
                answer += 1;
            }
        }

        return answer;
    }

    private boolean validate(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        boolean correct = true;

        for (char c : s.toCharArray()) {
            // 1. 여는 괄호면 스택에 추가
            boolean opening = c == '(' || c == '[' || c == '{';

            if (opening) {
                stack.push(c);
                continue;
            }

            // 2. 닫는 괄호인 경우
            // 2-1. 스택에 제거할 요소가 없으면 올바르지 않은 괄호로 판단
            if (stack.isEmpty()) {
                correct = false;
                break;
            }

            // 2-2. 스택의 마지막 요소와 짝이 맞지 않으면 올바르지 않은 괄호로 판단
            char top = stack.peek();
            boolean pair = top == '(' && c == ')' || top == '[' && c == ']' || top == '{' && c == '}';

            if (!pair) {
                correct = false;
                break;
            }

            // 2-3. 짝이 맞으면 스택에서 제거
            stack.pop();
        }

        // 스택이 최종적으로 비어있지 않으면 올바르지 않은 괄호로 판단.
        if (!stack.isEmpty()) {
            correct = false;
        }

        return correct;
    }
}
```

### Code (Python)

---

```python
def solution(s):
    x_count = 0

    for x in range(len(s)):
        rotated = s[x:] + s[0:x]
        stack = []

        for i in range(len(rotated)):
            if len(stack) == 0:
                stack.append(rotated[i])
            elif stack[-1] == '[' and rotated[i] == ']' or stack[-1] == '{' and rotated[i] == '}' or stack[-1] == '(' and rotated[i] == ')':
                stack.pop()
            else:
                stack.append(rotated[i])

        if len(stack) == 0:
            x_count += 1

    return x_count
```

- 슬라이싱 `s[x:] + s[:x]`으로 각 회전 문자열을 만든다.
- 리스트의 `append()`와 `pop()`으로 스택을 구현하고 회전마다 새 스택을 만든다.
- 시간 복잡도는 `O(N²)`, 보조 공간 복잡도는 `O(N)`이다.

### Code (C++)

---

```cpp
#include <stack>
#include <string>

using namespace std;

bool validate(const string& s) {
    stack<char> brackets;

    for (char c : s) {
        bool opening = c == '(' || c == '[' || c == '{';

        if (opening) {
            brackets.push(c);
            continue;
        }

        if (brackets.empty()) {
            return false;
        }

        char top = brackets.top();
        bool pair = top == '(' && c == ')' || top == '[' && c == ']' || top == '{' && c == '}';

        if (!pair) {
            return false;
        }

        brackets.pop();
    }

    return brackets.empty();
}

int solution(string s) {
    if (s.length() == 1) {
        return 0;
    }

    int answer = 0;

    for (int i = 1; i <= s.length(); i++) {
        string rotated = s.substr(i) + s.substr(0, i);

        if (validate(rotated)) {
            answer += 1;
        }
    }

    return answer;
}
```

- `stack<char>`의 `push()`, `top()`, `pop()`, `empty()`로 괄호의 후입선출 순서를 관리한다.
- `substr(i)`는 `i`부터 끝까지, `substr(0, i)`는 처음부터 `i`개 문자를 복사한다. 두 문자열을 연결해 왼쪽 회전을 만든다.
- `const string&`는 문자열을 복사하지 않고 읽기 전용 참조로 `validate()`에 전달한다.
- 범위 기반 `for (char c : s)`로 문자열의 문자를 순서대로 순회한다.
