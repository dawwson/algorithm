### Intuition

---

- 구명보트에는 최대 두 명만 탈 수 있으므로, **한 척에 두 명을 태울 수 있는 경우를 최대한 만드는 것이 보트 수를 줄이는 핵심**이다.
  - 사람을 몸무게순으로 정렬하면 가장 가벼운 사람과 가장 무거운 사람을 양 끝에서 바로 확인할 수 있다.
  - 가장 가벼운 사람과 가장 무거운 사람의 합이 제한을 초과하면, 가장 무거운 사람은 다른 누구와도 함께 탈 수 없다. 따라서 혼자 태워야 한다.
  - 두 사람의 합이 제한 이하면 함께 태운다. 가장 무거운 사람을 태우면서 함께 탈 수 있는 가장 가벼운 사람까지 처리하면 남은 사람들의 짝 구성 가능성을 최대한 보존할 수 있다.
  - 매번 가장 무거운 사람을 확정해서 보트 한 척에 태우므로, 두 포인터가 교차할 때까지 필요한 보트 수를 셀 수 있다.

- 이 풀이에서 **탐욕법은 현재 가장 무거운 사람을 기준으로 동승 여부를 즉시 결정하는 선택 전략**이고, **투 포인터는 정렬된 배열의 가장 가벼운 사람과 가장 무거운 사람을 효율적으로 가리키는 구현 기법**이다. 즉, 그리디 전략을 효율적으로 구현하기 위해 정렬과 투 포인터를 함께 사용한다.

<br>

### Approach

---

- 사용할 보트 수 `answer`를 `0`으로 초기화한다.
- 가장 가벼운 사람을 가리킬 `start`와 가장 무거운 사람을 가리킬 `end`를 배열의 양 끝에 배치한다.
- `Arrays.sort(people)`로 몸무게 배열을 오름차순 정렬한다.
- `start <= end`인 동안 다음 작업을 반복한다.
  - 가장 가벼운 사람과 가장 무거운 사람의 합이 `limit`보다 크면 가장 무거운 사람만 태우고 `end`를 감소시킨다.
  - 합이 `limit` 이하면 두 사람을 함께 태우고 `start`를 증가시키며 `end`를 감소시킨다.
  - 어느 경우든 보트 한 척을 사용했으므로 `answer`를 증가시킨다.
- 한 명만 남아 `start == end`인 경우에도 반복이 한 번 실행되어 그 사람을 위한 보트 한 척이 계산된다.
- 두 포인터가 교차하면 모든 사람을 태운 것이므로 `answer`를 반환한다.

<br>

### Complexity

---

- Time complexity: `O(n log n)`
  - `n`은 `people`의 길이이다.
  - `Arrays.sort()`로 기본형 `int` 배열을 정렬하는 데 `O(n log n)`이 필요하다.
  - 정렬 후 두 포인터는 배열의 각 원소를 최대 한 번씩 처리하므로 `O(n)`이다.

- Space complexity: `O(log n)`
  - Java의 기본형 배열 정렬 과정에서 재귀 호출 스택에 `O(log n)`의 보조 공간을 사용할 수 있다.
  - 정렬은 입력 배열 `people`을 직접 변경하며, 투 포인터와 카운터는 `O(1)` 공간만 사용한다.

<br>

### Code (Java)

---

```java
import java.util.Arrays;

class Solution {
    public int solution(int[] people, int limit) {

        int answer = 0;
        int start = 0;
        int end = people.length - 1;

        Arrays.sort(people);

        while (start <= end) {
            if (people[start] + people[end] > limit) {
                end -= 1;
            } else {
                start += 1;
                end -= 1;
            }

            answer += 1;
        }

        return answer;
    }
}
```

### Code (Python)

---

```python
def solution(people, limit):
    # 오름차순 정렬
    people.sort()
    # 가장 적게 나가는 사람 + 가장 많이 나가는 사람 태우기
    count = 0
    start = 0
    end = len(people) - 1

    while start < end:
        if people[start] + people[end] > limit:
            # 무거운 사람만 태움
            end -= 1
        else:
            # 둘 다 태움
            start += 1
            end -= 1
        count += 1

        # 마지막 한 명이 남으면 태움
        if start == end:
            count += 1
    return count
```

- `people.sort()`로 입력 리스트를 직접 오름차순 정렬하고 양 끝의 두 포인터로 탑승자를 결정한다.
- 두 사람을 함께 태울 수 없으면 가장 무거운 사람만 처리하고, 함께 탈 수 있으면 두 포인터를 모두 이동한다.
- 입력에 한 명만 있는 경우에는 `while start < end`가 실행되지 않아 `0`을 반환하는 경계 조건 문제가 있다.
- 사람 수를 `n`이라 할 때 정렬 때문에 시간 복잡도는 `O(n log n)`이고, Python 정렬의 임시 공간을 고려한 보조 공간 복잡도는 `O(n)`이다.
