### Intuition

---

- 캐시가 가득 찬 상태에서 새로운 도시를 저장하려면 가장 오래 사용하지 않은 도시를 제거해야 한다.
- 조회 순서를 유지하는 `LinkedHashMap`을 사용하면 캐시 조회와 LRU 순서 갱신을 함께 처리할 수 있다.
- `accessOrder`를 `true`로 설정하면 조회한 항목이 맨 뒤로 이동한다. 이때 맨 앞의 항목이 가장 오래 사용하지 않은 도시가 된다.
- 도시 이름은 대소문자를 구분하지 않으므로 조회 전에 소문자로 변환한다.

<br>

### Approach

---

1. `cacheSize`가 `0`이면 모든 요청이 cache miss이므로 `cities.length * 5`를 반환한다.
2. 접근 순서를 유지하는 `LinkedHashMap`을 생성한다.
3. 도시 이름을 소문자로 변환한다.
4. `cache.get(city)`의 결과가 `null`이 아니면 cache hit이다. 실행 시간에 `1`을 더하고 다음 도시를 처리한다. 조회된 도시는 접근 순서의 맨 뒤로 이동한다.
5. cache miss이고 캐시가 가득 찼다면 `keySet()`의 첫 번째 키를 제거한다.
6. 도시를 캐시에 저장하고 실행 시간에 `5`를 더한다.
7. 모든 도시를 처리한 뒤 누적 실행 시간을 반환한다.

<br>

### Complexity

---

- Time complexity: `O(N)`
  - `N`은 도시 이름의 개수이다.
  - 각 도시마다 대소문자 변환과 `LinkedHashMap`의 조회·삽입·삭제를 수행한다.
  - 도시 이름의 길이는 최대 20자로 제한되어 있어 대소문자 변환은 `O(1)`로 볼 수 있고, `LinkedHashMap` 연산도 평균 `O(1)`이므로 전체 시간 복잡도는 `O(N)`이다.

- Space complexity: `O(C)`
  - `C`는 캐시의 크기이다.
  - 캐시에는 최대 `C`개의 도시 이름이 저장된다.
  - 도시 이름의 길이는 최대 20이므로 `O(C)`로 볼 수 있다.

<br>

### Code (Java)

---

```java
import java.util.Map;
import java.util.LinkedHashMap;

class Solution {
    public int solution(int cacheSize, String[] cities) {

        if (cacheSize == 0) {
            return cities.length * 5;
        }

        Map<String, Boolean> cache = new LinkedHashMap<>(cacheSize, 0.75f, true);

        int time = 0;

        for (String city : cities) {
            city = city.toLowerCase();

            if (cache.get(city) != null) {
                time += 1;
                continue;
            }

            if (cache.size() == cacheSize) {
                String firstKey = cache.keySet().iterator().next();
                cache.remove(firstKey);
            }

            cache.put(city, true);
            time += 5;
        }

        return time;
    }
}
```

### Code (Python)

---

```python
def solution(cacheSize, cities):
    # 캐시를 사용하지 않으면 DB로 접근
    if cacheSize == 0:
        return 5 * len(cities)

    # 사용된지 오래된 순으로 정렬됨
    cache = []
    time = 0

    for city in cities:
        city = city.lower()

        # cache hit
        if city in cache:
            time += 1
            # 사용된 값을 맨 뒤로 보냄
            used = cache.pop(cache.index(city))
            cache.append(used)
        # cache miss
        else:
            time += 5
            # 캐시에 남은 용량이 없으면 가장 오래된 데이터 삭제
            if len(cache) == cacheSize:
                cache = cache[1:]
            cache.append(city)
    return time
```

- `cache`의 앞쪽에는 오래전에 사용한 도시, 뒤쪽에는 최근에 사용한 도시를 둔다.
- cache hit이면 해당 도시를 찾아 제거한 뒤 맨 뒤에 추가한다. cache miss이고 캐시가 가득 찼다면 첫 번째 도시를 제거한다.
- 도시 수를 `N`, 캐시 크기를 `C`, 도시 이름의 최대 길이를 `L`이라 할 때 시간 복잡도는 `O(N × C × L)`이다. `L ≤ 20`이므로 `O(N × C)`로 볼 수 있다.
- 캐시에 최대 `C`개의 도시 이름을 저장하므로 보조 공간 복잡도는 `O(C × L)`이다. `L ≤ 20`이므로 `O(C)`로 볼 수 있다.
