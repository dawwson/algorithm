### Intuition

---

- 프로세스는 대기 순서의 맨 앞에서 꺼내고, 더 높은 우선순위가 남아 있으면 다시 맨 뒤로 보낸다. 이 순서 변화를 그대로 처리하기 위해 큐를 사용한다.
- 실행 여부를 결정하려면 현재 프로세스의 우선순위가 남아 있는 우선순위 중 최댓값인지 확인해야 한다. 최대 힙을 함께 사용하면 최댓값을 바로 조회할 수 있다.
- 같은 우선순위가 여러 개일 수 있으므로 우선순위만으로는 목표 프로세스를 구분할 수 없다. 각 프로세스에 원래 인덱스를 함께 저장한다.

<br>

### Approach

---

1. 각 프로세스의 인덱스와 우선순위를 `Queue<int[]>`에 저장한다.
2. 모든 우선순위를 내림차순 `PriorityQueue<Integer>`에 저장한다.
3. 큐의 맨 앞 프로세스를 꺼낸다.
4. 현재 우선순위가 `pq.peek()`보다 낮으면 프로세스를 큐의 맨 뒤에 다시 넣는다.
5. 현재 우선순위가 `pq.peek()`와 같으면 프로세스를 실행한다. 우선순위 큐에서도 최댓값을 제거하고 실행 순서를 증가시킨다.
6. 실행한 프로세스의 인덱스가 `location`이면 실행 순서를 반환한다.
7. 목표 프로세스가 실행될 때까지 같은 과정을 반복한다.

<br>

### Complexity

---

> `N`: 프로세스의 개수

- Time complexity: `O(N log N)`
  - 우선순위 큐에 `N`개의 값을 삽입하고 제거하는 데 `O(N log N)`이 필요하다.
  - 일반 큐의 삽입과 제거는 `O(1)`이다. 우선순위가 `1`부터 `9`까지이므로 한 프로세스가 뒤로 이동하는 횟수는 상수 범위이다.

- Space complexity: `O(N)`
  - 일반 큐에 최대 `N`개의 프로세스, 우선순위 큐에 최대 `N`개의 우선순위를 저장한다.

<br>

### Code (Java)

---

```java
import java.util.*;

class Solution {
    public int solution(int[] priorities, int location) {

        Queue<int[]> queue = new LinkedList<>();
        PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());

        for (int i = 0; i < priorities.length; i++) {
            queue.offer(new int[]{i, priorities[i]});
            pq.offer(priorities[i]);
        }

        int order = 0;

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int idx = cur[0];
            int priority = cur[1];

            // 현재 문서가 가장 높은 우선순위라면 출력
            if (priority == pq.peek()) {
                pq.poll();
                order++;

                if (idx == location) {
                    return order;
                }
            } else {
                // 아니면 다시 큐 뒤로
                queue.offer(cur);
            }
        }

        return order;
    }
}

```

### Code (Python)

---

```python
def solution(priorities, location):
    order = 0
    queue = [(i, priority) for i, priority in enumerate(priorities)]

    while True:
        i, priority = queue.pop(0)

        if any(priority < process[1] for process in queue):
            queue.append((i, priority))
        else:
            order += 1

            if i == location:
                return order
```

- `enumerate()`로 원래 위치와 우선순위를 튜플로 묶어 추적한다.
- `queue`가 리스트이므로 `pop(0)`은 나머지 원소를 이동하는 데 `O(N)`이 필요하다.
- `any()`도 남은 프로세스의 우선순위를 최대 `N`개 확인하므로 `O(N)`이다.
- 우선순위가 `1~9`로 제한되어 전체 큐 순회 횟수는 `O(N)`이므로, 시간 복잡도는 `O(N²)`이다.
- 프로세스 튜플을 최대 `N`개 저장하므로 보조 공간 복잡도는 `O(N)`이다.

### Code (C++)

---

```cpp
#include <queue>
#include <utility>
#include <vector>

using namespace std;

int solution(vector<int> priorities, int location) {
    // 프로세스 현재 대기 순서
    queue<pair<int, int>> q; // <priority, location>
    // 우선순위 확인
    priority_queue<int> pq;

    for (int i = 0; i < priorities.size(); i++) {
        q.push({priorities[i], i});
        pq.push(priorities[i]);
    }

    int order = 0; // 몇번째로 실행되는지

    while (!pq.empty()) {
        auto [priority, index] = q.front();
        q.pop();

        if (priority == pq.top()) {
            pq.pop();
            order += 1;

            if (index == location) {
                break;
            }
        } else {
            q.push({priority, index});
        }
    }

    return order;
}
```

- `queue<pair<int, int>>`는 프로세스의 우선순위와 원래 위치를 묶어 FIFO 순서로 관리한다. `front()`, `pop()`, `push()`로 맨 앞 프로세스를 꺼내거나 뒤로 보낸다.
- `priority_queue<int>`는 기본적으로 최대 힙이며, `top()`으로 현재 남은 최댓값을 확인한다. `push()`와 `pop()`의 시간 복잡도는 `O(log n)`이다.
- `pair`의 중괄호 초기화 `{priorities[i], i}`로 두 값을 함께 저장한다.
- 구조적 바인딩 `auto [priority, index]`으로 `pair`의 두 값을 각각의 변수로 분해한다.
