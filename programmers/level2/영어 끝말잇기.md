### Intuition

---

- 끝말잇기에서 탈락 조건은 이전에 등장한 단어를 다시 말하거나, 앞 단어의 마지막 문자로 시작하지 않는 경우이다.
- 단어가 이미 등장했는지 매번 앞의 모든 단어와 비교하면 검사에 최대 `O(m²)`이 필요하다.
- 지금까지 나온 단어를 `HashSet`에 저장하면 중복 여부를 평균 `O(1)`에 확인할 수 있다.
- 단어는 입력 순서대로 주어지므로, 처음 규칙을 어긴 위치를 찾는 즉시 탈락자의 번호와 차례를 계산하면 된다.
- 배열 인덱스 `i`가 `0`부터 시작할 때 참가자 번호는 `i % n + 1`, 해당 참가자의 차례는 `i / n + 1`이다.

<br>

### Approach

---

- 지금까지 등장한 단어를 저장할 `HashSet`과 결과를 저장할 길이 `2`의 `answer` 배열을 생성한다.
- 첫 번째 단어는 비교할 이전 단어가 없으므로 먼저 Set에 추가한다.
- 두 번째 단어부터 마지막 단어까지 순회한다.
  - `before`에 바로 앞 단어를, `current`에 현재 단어를 저장한다.
  - `set.contains(current)`로 현재 단어가 이미 등장했는지 확인한다.
  - 앞 단어의 마지막 문자와 현재 단어의 첫 문자가 다른지 확인한다.
  - 두 조건 중 하나라도 참이면 잘못된 단어이므로 현재 인덱스를 이용해 탈락자의 번호와 차례를 계산한다.
  - 계산한 값을 `answer`에 저장하고 반복을 종료한다.
  - 규칙을 지켰다면 현재 단어를 Set에 추가하고 다음 단어를 검사한다.
- 탈락자가 없으면 초기값 `[0, 0]`이 그대로 반환된다.

<br>

### Complexity

---

- Time complexity: `O(n)`
  - `n`은 `words`에 포함된 단어의 수이다.
  - 각 단어를 최대 한 번씩 확인하며 `HashSet`의 조회와 추가는 평균 `O(1)`이다.
  - 문자열 해시 계산 비용까지 구분하면 전체 시간은 검사한 단어들의 문자 수 합에 비례한다.

- Space complexity: `O(n)`
  - 탈락자가 나오기 전까지 등장한 단어를 `HashSet`에 최대 `n`개 저장한다.
  - Set은 입력 문자열의 참조를 저장하며 문자열 자체를 복사하지 않는다.

<br>

### Code (Java)

---

```java
import java.util.Set;
import java.util.HashSet;

class Solution {
    public int[] solution(int n, String[] words) {

        Set<String> set = new HashSet<>();
        int[] answer = new int[2];

        set.add(words[0]);

        for (int i = 1; i < words.length; i++) {
            String before = words[i-1];
            String current = words[i];

            boolean incorrect = set.contains(current)
                || before.charAt(before.length() - 1) != current.charAt(0);

            if (incorrect) {
                int number = i % n + 1;
                int turn = i / n + 1;

                answer[0] = number;
                answer[1] = turn;

                break;
            }

            set.add(current);
        }

        return answer;
    }
}
```

### Code (Python)

---

```python
def solution(n, words):
    turns = dict.fromkeys([i for i in range(n)], 0)
    used = []

    for index, word in enumerate(words):
        turns[index % n] += 1

        # 이미 나온 단어를 말하면 탈락
        if used.count(word) != 0:
            return [index % n + 1, turns[index % n]]
        # 끝말잇기가 안 되면 탈락
        if len(used) != 0 and used[-1][-1] != word[0]:
            return [index % n + 1, turns[index % n]]
        used.append(word)

    return [0, 0]
```

- 참가자별 차례를 `turns` 딕셔너리에 누적하고, 사용한 단어를 `used` 리스트에 순서대로 저장한다.
- `used.count(word)`로 중복을 검사하고 마지막 단어와 현재 단어의 문자를 비교해 연결 규칙을 확인한다.
- 단어 수를 `m`, 참가자 수를 `n`이라 할 때 `count()`의 반복적인 선형 탐색 때문에 최악의 시간 복잡도는 `O(m²)`, 보조 공간 복잡도는 `O(m + n)`이다.
