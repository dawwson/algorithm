### Intuition

---

- 현재 위치에서 사전에 있는 가장 긴 문자열 `w`를 찾아 색인 번호를 출력해야 한다.
- 문자를 하나씩 붙이며 사전을 조회하면 처음으로 사전에 없는 문자열을 만났을 때 직전 문자열이 `w`임을 알 수 있다.
- 사전에 없는 문자열은 `w`와 다음 문자 `c`를 합친 `w + c`이므로 새 색인 번호로 등록한다.
- 문자열과 색인 번호를 반복해서 조회하고 추가하므로 `HashMap`을 사용한다.

<br>

### Approach

---

1. `A`부터 `Z`까지의 문자열과 색인 번호 `1`부터 `26`을 `dict`에 저장한다.
2. 현재 위치 `i`에서 시작해 `StringBuilder`에 문자를 하나씩 추가한다.
3. 만든 문자열이 사전에 있으면 색인 번호와 문자열 길이를 `maxIndex`, `wLength`에 저장하고 탐색을 계속한다.
4. 만든 문자열이 사전에 없으면 다음 색인 번호로 등록하고 탐색을 중단한다.
5. 사전에 있던 가장 긴 문자열의 색인 번호를 `answer`에 추가한다.
6. `i`를 `wLength`만큼 옮겨 다음 문자열을 처리한다.
7. `answer`를 `int[]`로 변환해 반환한다.

<br>

### Complexity

---

> `N`: 입력 문자열 `msg`의 길이

- Time complexity: `O(N²)`
  - 각 위치에서 접두사를 늘리는 과정에서 `StringBuilder.toString()`으로 새 문자열을 만들고 해시 조회를 수행한다.
  - 길이가 `k`인 문자열을 생성하고 해시값을 계산하는 데 `O(k)`가 필요하므로 전체 비용의 상한은 `O(N²)`이다.
  - 결과 리스트를 배열로 변환하는 데 `O(N)`이 추가된다.

- Space complexity: `O(N)`
  - 사전에 추가되는 문자열 길이의 합과 결과 리스트의 크기는 입력 길이에 비례한다.
  - 탐색 중 생성되는 `StringBuilder`와 임시 문자열도 최대 `O(N)`의 공간을 사용한다.

### Code (Java)

---

```java
import java.util.Map;
import java.util.HashMap;
import java.util.List;
import java.util.ArrayList;

class Solution {
    public int[] solution(String msg) {

        Map<String, Integer> dict = new HashMap<>();
        List<Integer> answer = new ArrayList<>();

        int lastIndex = 26;

        for (int i = 0; i < lastIndex; i++) {
            String word = String.valueOf((char) ('A' + i));
            dict.put(word, i + 1);
        }

        int i = 0;

        while (i < msg.length()) {
            StringBuilder input = new StringBuilder();

            int maxIndex = 0;
            int wLength = 0;

            for (int j = i; j < msg.length(); j++) {
                input.append(msg.charAt(j));

                String w = input.toString();

                if (dict.containsKey(w)) {
                    maxIndex = dict.get(w);
                    wLength = w.length();
                } else {
                    lastIndex += 1;
                    dict.put(w, lastIndex);
                    break;
                }
            }

            answer.add(maxIndex);
            i += wLength;
        }

        return answer.stream()
            .mapToInt(Integer::intValue)
            .toArray();
    }
}
```

### Code (Python)

---

```python
def solution(msg):
    # { 'A': 1, 'B': 2, ...}
    words = {chr(i+64): i for i in range(1, 27)}
    last = 27
    answer = []

    while True:
        if msg in words:
            answer.append(words[msg])
            break

        for i in range(1, len(msg)+1):
            # 사전에 없으면
            if msg[:i] not in words:
                # 색인 번호 출력(그 앞 글자까지만)
                answer.append(words[msg[:i-1]])

                # 사전에 등록
                words[msg[:i]] = last
                last += 1

                # 입력값 수정
                msg = msg[i-1:]
                break

    return answer
```

- `words`에 없는 첫 접두사를 찾고, 바로 앞 접두사의 색인을 결과에 추가한다.
- 새 접두사를 사전에 등록한 뒤 처리한 부분을 제외한 문자열을 `msg`에 다시 저장한다.
- 반복적인 문자열 슬라이싱과 해시 조회 때문에 시간 복잡도는 `O(N²)`이다.
- 사전, 결과 리스트, 슬라이스된 문자열에 필요한 보조 공간은 `O(N)`이다.
