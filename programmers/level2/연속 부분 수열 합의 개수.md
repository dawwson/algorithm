### Intuition

---

- 구해야 하는 값은 부분 수열의 개수가 아니라 **서로 다른 합의 개수**이다. 같은 합이 여러 번 나와도 한 번만 세면 되므로 합을 `HashSet`에 저장한다.
- 길이가 `N`인 원형 수열에서는 시작 위치 `N`개와 부분 수열 길이 `N`개를 조합해 모든 연속 부분 수열을 확인할 수 있다. `N`이 최대 1,000이므로 `N²`개의 경우를 직접 확인할 수 있다.
- 원형 수열은 마지막 원소 다음에 첫 번째 원소가 이어진다. `(현재 인덱스) % N`을 사용하면 배열을 이어 붙이지 않고 다음 원소의 위치를 구할 수 있다.
- 각 시작 위치에서 길이를 하나씩 늘릴 때 이전 합에 새 원소만 더한다. 구간의 합을 매번 처음부터 계산하는 `O(N³)` 방식 대신 모든 합을 `O(N²)`에 구할 수 있다.

<br>

### Approach

---

1. 원형 수열의 각 인덱스를 부분 수열의 시작 위치 `start`로 선택한다.
2. 시작 위치가 바뀔 때마다 누적 합 `sum`을 `0`으로 초기화한다.
3. 부분 수열의 길이를 `1`부터 `N`까지 늘린다.
4. `(start + length - 1) % N`으로 이번에 더할 원소의 인덱스를 구한다.
5. 해당 원소를 `sum`에 더하고 결과를 `set`에 저장한다.
6. 모든 시작 위치와 길이를 확인한 뒤 `set`의 크기를 반환한다.

<br>

### Complexity

---

> `N`: `elements`의 길이  
> `S`: 서로 다른 연속 부분 수열 합의 개수

- Time complexity: `O(N²)`
  - `N`개의 시작 위치마다 길이 `1`부터 `N`까지 확인한다.
  - 각 단계의 덧셈과 `HashSet` 연산은 평균 `O(1)`이다.

- Space complexity: `O(S)`, worst case `O(N²)`
  - `HashSet`에 서로 다른 합을 최대 `S`개 저장한다.
  - 확인하는 부분 수열이 `N²`개이므로 `S`의 상한은 `N²`이다.

<br>

### Code (Java)

---

```java
import java.util.Set;
import java.util.HashSet;

class Solution {
    public int solution(int[] elements) {

        Set<Integer> set = new HashSet<>();
        int n = elements.length;

        for (int start = 0; start < n; start++) {
            int sum = 0;

            for (int length = 1; length <= n; length++) {
                sum += elements[(start + length - 1) % n];
                set.add(sum);
            }
        }

        return set.size();
    }
}
```

### Code (Python)

---

```python
def solution(elements):
    sum_set = set()

    # x : 연속 부분 수열의 길이
    for l in range(1, len(elements)+1):
        # 연속 부분 수열의 시작 인덱스
        for start in range(len(elements)):
            subtotal = 0

            if start+l > len(elements):
                subtotal = sum(elements[start:] + elements[:start+l-len(elements)])
            else:
                subtotal = sum(elements[start:start+l])

            sum_set.add(subtotal)

    return len(sum_set)
```

- 슬라이싱과 리스트 연결로 원형 구간을 만들고 `sum()`으로 각 구간의 합을 계산한다.
- 길이와 시작 위치를 각각 `N`번 순회하고, 구간 생성과 합 계산에 최대 `O(N)`이 필요하므로 시간 복잡도는 `O(N³)`이다.
- 합 집합과 임시 구간에 필요한 보조 공간은 `O(S + N)`, 최악의 경우 `O(N²)`이다.

### Code (C++)

---

```cpp
#include <unordered_set>
#include <vector>

using namespace std;

int solution(vector<int> elements) {
    unordered_set<int> sums;
    int n = elements.size();

    for (int start = 0; start < n; start++) {
        int sum = 0;

        for (int length = 1; length <= n; length++) {
            sum += elements[(start + length - 1) % n];
            sums.insert(sum);
        }
    }

    return sums.size();
}
```

- `unordered_set<int>`는 해시 기반 집합이다. `insert()`로 중복을 제거하며 합을 저장하고 `size()`로 서로 다른 합의 개수를 구한다.
- `% n`으로 인덱스를 수열 범위 안에 유지해 마지막 원소 다음에 첫 번째 원소가 이어지도록 처리한다.
- `vector<int>`의 `size()`로 수열 길이를 구하고 `operator[]`로 원소에 접근한다.
